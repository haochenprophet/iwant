# 02 · C 语言学习笔记

> 原文出处：CSDN「斑马819」《C语言学习笔记》系列，共 15 篇，发布于 2026-07-21 至 2026-08-06。

## 一、系列定位

本系列是知识库的第 2 个系列，上承 `01-linux-basics` 的命令行与编辑器，下启 `03-data-structure` 与 `04-linux-sysprog`，是整条学习路径里唯一的 C 语言语法专项。它按"能编译、会存数据、会控制流程、能组织数据、懂指针、管得住内存"的顺序推进，把 15 个主题压成一条连续的线，而不是零散的语法点。目标是让你能独立写出带输入输出、数组、函数与动态内存的 C 程序，并说清每一行代码在内存里发生了什么。它也是后续单片机与 ARM 裸机开发中直接操作寄存器的语言前提。

## 二、前置知识与环境

- **Linux 基础**：终端操作、文件与目录命令、权限概念，对应 [Linux 基础入门](../01-linux-basics/01-虚拟机、终端及常用命令详解.md)。
- **文本编辑**：会用 `vi`/`vim` 打开、修改并保存 `.c` 源文件。
- **编译器**：Linux 下的 `gcc`，能跑通 `gcc hello.c -o hello` 与 `./hello`。
- **平台约定**：笔记中的类型长度按 Linux 64 位环境给出（`short` 2 字节、`int` 4 字节、`long` 8 字节），换平台后数值会变。
- **二进制常识**：知道 bit 与 Byte、1 Byte = 8 bit、1 KB = 1024 Byte，能读二进制、八进制、十进制与十六进制。
- **常用头文件**：`<stdio.h>`、`<stdbool.h>`、`<string.h>`、`<stdlib.h>`。
- **练习方式**：示例要自己敲、自己看运行结果；指针与内存两段允许反复回看。

## 三、知识脉络

15 篇按"先会用、再会组织、最后会管内存"的顺序推进，可分成 6 个阶段：

1. **打通工具链，认识数据（01–03）**：先走通 GCC 的预处理、编译、汇编、链接四步，再补数据单位、进制与基本类型，最后用 `printf`/`scanf` 完成输入输出。这一阶段结束时，你已经能写出有输入、有输出的完整小程序。
2. **让程序会判断、会重复（04–05）**：关系与逻辑运算符、三目运算符撑起分支，`if` 与 `switch` 落地；`while`、`for`、`do...while` 配合 `break`/`continue` 撑起循环。程序从"顺序执行"变成"有逻辑"。
3. **批量组织数据（06–08）**：一维数组解决"一批同类型数据"，字符数组与 `string.h` 解决文本，二维数组解决表格，二维字符数组解决"多个字符串"；第 08 篇同时引入函数，为下一篇铺路。
4. **从平铺到模块化（09）**：函数的定义、声明、调用，值传递/全局变量/数组传参三种数据通道，递归，以及宏、带参宏、头文件包含。代码第一次可以拆分、复用与单独调试。
5. **指针三级跳（10–12）**：第 10 篇打地基（地址、解引用、数组与指针等价），第 11 篇进阶（地址传递带回多值、指针函数、函数指针、三种 `const`），第 12 篇攻难点（二级指针、指针数组、数组指针）。原文把指针称作 C 语言学习的"分水岭"。
6. **构造类型与内存收尾（13–15）**：结构体（含内存对齐）、共用体与枚举、位运算，最后用内存五分区与 `malloc`/`calloc`/`realloc`/`free` 把前面所有内容收束到"申请—使用—释放"的闭环。

## 五、核心要点

### 5.1 数据类型与运算符

- 数据类型（Data Type）决定数据占多少内存、能存什么数据：Linux 64 位下 `short` 2 字节、`int` 4 字节、`long` 8 字节；`float` 4 字节（6~8 位有效数字）、`double` 8 字节（12~16 位）。
- 整数还分 `signed` 与 `unsigned`：`unsigned` 不能表示负数，但能表示更大的正整数。
- 布尔类型需要 `#include <stdbool.h>`，`true` 为 1、`false` 为 0，语言层面的规则是"非 0 即真"。
- 混合类型运算自动提升：`int` 与 `double` 相加得到 `double`；强制转换 `(int)3.14` 得到 `3`，小数部分被直接舍弃。
- `a++` 先使用后加 1，`++a` 先加 1 后使用；`sizeof` 用来查看变量或类型占用的字节数。

### 5.2 数组与字符串

- 数组（Array）是同类型元素的连续集合，`int num[5]` 的下标是 `0`~`4`，长度定义后不能改；只初始化前几个元素时，其余自动补 0。
- C 没有独立的字符串类型，字符串就是以 `'\0'`（null terminator）结尾的字符数组，`char str[6] = "hello"` 必须留一格给 `'\0'`。
- `strlen()` 统计长度时不含 `'\0'`，`sizeof()` 返回整个数组占用的字节数，两者不能互相替代。
- `strcpy()` 要求目标数组足够大，`strcat()` 拼接后不能超过目标容量，`strcmp()` 返回 0 表示相等、大于 0 表示前者大、小于 0 表示前者小。
- 二维数组是"由多个一维数组组成的数组"，`int a[2][3]` 用嵌套 `for` 遍历；二维字符数组 `char name[4][20]` 可存 4 个字符串，每个最长 19 个字符加一个 `'\0'`。

```c
char str[] = "hello";
int len = 0;
while (str[len] != '\0') len++;   /* 不用 strlen，len 最终为 5 */
```

### 5.3 函数与预处理

- 函数（Function）的定义格式是 `返回值类型 函数名(参数列表)`，函数体末尾用 `return` 返回结果；若定义写在 `main()` 之后，必须在调用前声明，声明要给出返回值类型与参数类型。
- 值传递：形参（Formal Parameter）只是实参（Actual Parameter）的副本，函数内改形参不影响外部变量。
- 数组传参时 `int fun(int arr[], int len)` 与 `int fun(int *arr, int len)` 效果相同，函数内操作的就是原数组，因此必须另外把长度传进去。
- 递归（Recursion）必须在函数内写结束条件，并避免过深，否则会无限调用或耗尽栈空间。
- 预处理命令在编译前执行，包括宏定义、条件编译与头文件包含；宏（Macro）只是文本替换，带参宏如 `#define MAX(a,b) ((a)>(b)?(a):(b))` 要同时给每个参数和整个表达式加括号。

### 5.4 指针家族

- 指针（Pointer）是保存地址的变量：`&` 取地址，`*` 解引用（Dereference），打印地址用 `%p`；`int *p = &num; *p = 100;` 可直接改写 `num` 所在内存的数据。
- 野指针（Wild Pointer）是未初始化或指向已释放空间的指针，空指针（Null Pointer）是值为 `NULL`（地址 `0x0`）的指针，两者解引用都会出问题。
- `p++` 不是加 1 个字节，而是向高地址移动一个 `sizeof(指针所指类型)` 的距离。
- 一维数组的数组名等价于 `&a[0]`，可理解为指向首元素的指针常量；`a[i]`、`*(a+i)`、`p[i]`、`*(p+i)` 是等价的四种写法。
- 指针做参数即地址传递，能在函数内修改外部变量，也能用 `*sum`、`*sub` 这类出参带回多个结果；指针函数（返回指针的函数）不能返回局部变量地址，只能返回动态申请的空间或全局变量地址。
- 函数指针（Function Pointer）指向函数：`int (*p)(int, int); p = add; p(10, 20);`；二级指针（Pointer to Pointer）保存一级指针的地址，`int **pp = &p;` 时 `**pp` 才到达最终变量。
- 指针数组 `int *p[5]` 是数组、元素为指针；数组指针 `int (*p)[5]` 是指针、指向含 5 个 `int` 的数组；`const int *p` 数据不可改，`int *const p` 指针不可改，`const int *const p` 两者都不可改。

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;                        /* 等价于 p = &a[0] */
printf("%d %d\n", *(p + 2), p[2]); /* 30 30 */
```

### 5.5 构造类型与内存

- 结构体（Structure）把不同类型成员组合成一个整体：普通变量用 `.` 访问成员，指针用 `->` 访问；初始化既可严格按成员顺序，也可用 `.name = "zhangsan"` 指定成员。
- 内存对齐（Memory Alignment）：每个成员的地址必须是其自身类型长度的整数倍，结构体总大小必须是最大基本类型长度的整数倍，可用 `#pragma pack(n)` 手动调整。
- 共用体（Union）的所有成员共享同一块内存，同一时刻只有一个成员有效，大小取最大成员；枚举（Enumeration）表示一组固定取值，默认从 0 开始递增，可读性优于裸数字。
- 位运算（Bitwise Operation）：`5 & 3 = 1`、`5 | 3 = 7`、`5 ^ 3 = 6`、`5 << 1 = 10`、`8 >> 1 = 4`；`num & 1` 判奇偶，`a |= (1 << 3)` 置位，`a &= ~(1 << 3)` 清位。
- 程序内存从高地址到低地址分为栈区（Stack）、堆区（Heap）、全局区、常量区、代码区；栈放局部变量与函数参数，自动分配自动释放，堆放 `malloc` 申请的空间，手动申请手动释放。
- 动态内存四函数都在 `<stdlib.h>`：`malloc` 申请、`calloc` 申请并清零、`realloc` 调整大小、`free` 释放；申请后必须判 `NULL`，用完必须 `free`，原则是"申请 → 使用 → 释放"。

```c
int *p = (int *)malloc(10 * sizeof(int));
if (p == NULL) return -1;
p[0] = 100;
free(p);
p = NULL;                     /* 置空，避免留下野指针 */
```

## 六、易错点与踩坑

1. **数组越界**：`int num[5]` 的合法下标只有 `0`~`4`，访问 `num[5]` 属于非法访问，可能引发不可预知的错误；`malloc(5 * sizeof(int))` 之后写 `p[10]` 同样是越界。
2. **漏掉 `'\0'`**：字符串必须以 `'\0'` 结尾，定义字符数组时要预留这一格；另外 `strlen` 不计 `'\0'`、`sizeof` 计整个数组，不能混用。
3. **把数组名当成普通指针**：数组名等价于 `&a[0]`，可理解为指向首元素的指针常量，`p = a` 可以，但 `a` 本身不能再被赋值为别的地址。
4. **指望值传递修改实参**：`void change(int x) { x = 100; }` 调用后外部变量仍是 10，要改外部变量只能传地址。
5. **野指针与空指针**：`int *p; *p = 10;` 指向不明；`int *p = NULL; *p = 10;` 访问 `0x0` 地址会直接崩溃。
6. **指针函数返回局部变量地址**：函数结束时局部变量空间已被释放，返回的地址随即失效，应改为返回动态申请的空间或全局变量地址。
7. **`scanf` 用法错**：除字符数组外必须加 `&`，格式符要与数据类型匹配；连续读取字符时用 `" %c"` 吃掉上一次留下的空格或换行。
8. **用 `gets()` 读整行**：它不检查数组长度，容易造成缓冲区（Buffer）溢出，C11 已将其移除，应改用 `fgets(str, sizeof(str), stdin)`。
9. **`switch` 漏写 `break`**：程序会继续向下执行（贯穿）；此外 `switch` 后面的表达式必须是整型，`case` 后只能是常量。
10. **动态内存用法错**：申请后不判 `NULL`、用完不 `free` 造成内存泄漏、`free` 两次导致重复释放、`free` 后不置 `NULL` 留下野指针。

## 七、关键术语

| 术语 | 说明 |
| --- | --- |
| 预处理（Preprocessing） | 编译前处理以 `#` 开头的指令：展开头文件、替换宏、条件编译、删除注释 |
| 链接（Link） | 把目标文件与标准库、系统库组合成可执行程序，`printf` 的实现就来自标准库 |
| 宏（Macro） | 预处理阶段的纯文本替换，不占内存也不做计算，建议参数与整体都加括号 |
| 字符串结束符（Null Terminator） | 字符数组中的 `'\0'`，标记字符串到此结束，`strlen` 不统计它 |
| 指针（Pointer） | 保存内存地址的变量，`int *p` 表示指向整型数据的指针 |
| 解引用（Dereference） | 用 `*` 通过地址访问对应空间里的数据，`*p = 100` 即改写该地址的内容 |
| 野指针（Wild Pointer） | 未初始化、或指向已经释放空间的指针，解引用行为不可预期 |
| 空指针（Null Pointer） | 值为 `NULL`（地址 `0x0`）的指针，空地址不可访问，解引用会导致崩溃 |
| 二级指针（Pointer to Pointer） | 保存一级指针地址的指针，`int **pp = &p` 时 `**pp` 才到达最终变量 |
| 指针数组（Array of Pointers） | 元素全是指针的数组，`int *p[5]` 表示 5 个 `int *` 元素 |
| 数组指针（Pointer to Array） | 指向一个数组的指针，`int (*p)[5]` 指向包含 5 个 `int` 的数组 |
| 函数指针（Function Pointer） | 指向函数的指针，`int (*p)(int, int)` 赋值后可像函数一样调用 |
| 结构体（Structure） | 用 `struct` 把不同类型成员组合成逻辑整体，成员用 `.` 或 `->` 访问 |
| 内存对齐（Memory Alignment） | 成员地址取其类型长度的整数倍、总大小取最大基本类型长度整数倍的存储规则 |
| 共用体（Union） | 所有成员共享同一块内存，同一时刻只有一个成员有效，大小等于最大成员 |
| 位运算（Bitwise Operation） | 直接对二进制位做按位与、按位或、按位异或、取反与移位，常用于置位、清位与奇偶判断 |
| 栈区（Stack） | 存放局部变量与函数参数，由系统自动分配和释放，空间较小但速度快；相对的堆区由程序员用 `malloc` 与 `free` 管理 |
| 内存泄漏（Memory Leak） | 申请的堆空间失去引用又没有 `free`，程序再也无法回收这块内存 |

## 八、延伸与衔接

- **→ 数据结构（`03-data-structure`）**：结构体、指针与 `malloc`/`free` 正是线性表的实现材料。[顺序表](../03-data-structure/01-顺序表（SeqList）.md) 用"结构体 + 数组 + 容量"管理一批数据，对应第 13、15 篇；[单向链表](../03-data-structure/02-单向链表.md) 要让结构体指针指向自身，是第 10、12 篇的直接延续；[双向链表、循环链表](../03-data-structure/03-双向链表、循环链表.md) 与 [顺序队列与链式队列](../03-data-structure/04-顺序队列与链式队列.md) 靠指针改链，正好检验第 12 篇；[二叉树与非递归遍历](../03-data-structure/05-二叉树与非递归遍历.md) 会把第 09 篇的递归、第 13 篇的结构体与第 10~12 篇的指针一起用上。
- **→ Linux 系统编程（`04-linux-sysprog`）**：[标准IO](../04-linux-sysprog/02-标准IO.md) 承接第 03 篇的 `printf`/`scanf` 与第 07 篇的字符串处理；[文件IO与目录IO](../04-linux-sysprog/03-文件IO与目录IO.md) 承接第 15 篇的内存与缓冲区概念；[进程](../04-linux-sysprog/04-进程.md)、[线程](../04-linux-sysprog/05-线程.md) 需要理解栈区、全局区与堆区的划分（第 15 篇），其中的指针传参与动态缓冲区依赖第 10~12 篇。
- **→ 硬件方向（`05-mcu-8051`、`06-arm-imx6ull`）**：寄存器读写、置位清位与标志位判断对应第 14 篇的位运算，用指针访问固定地址对应第 10 篇的地址概念。
