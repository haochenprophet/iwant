## 一、前言

在前面的学习中，我们已经学习了：

- 基本数据类型
- 数组
- 函数
- 指针
- 结构体
- 共用体
- 枚举
- 位运算

其中，指针最大的作用就是：

> 通过地址操作内存。

因此，理解 C 语言的内存管理机制，是深入学习 C 语言的重要基础。

在实际开发过程中，经常需要：

- 动态创建数据
- 根据用户输入申请空间
- 手动释放不再使用的内存

这些操作都涉及：

**内存管理。**

---

## 二、程序运行时的内存区域

C语言程序运行时，内存主要分为以下几个区域：

```
高地址

+----------------+
|     栈区       |
+----------------+
|     堆区       |
+----------------+
|     全局区     |
+----------------+
|     常量区     |
+----------------+
|     代码区     |
+----------------+

低地址
```

---

## 三、代码区（Code Segment）

代码区用于存放：

> 程序执行的机器指令。

例如：

```c
int main()
{
    printf("hello");
}
```

编译后的指令存放在代码区。

特点：

- 只读
- 程序运行期间一直存在

---

## 四、常量区

用于存放程序中的常量数据。

例如：

```c
printf("Hello World");
```

字符串：

```
Hello World
```

存储在常量区。

特点：

- 生命周期贯穿程序运行
- 不允许修改

例如：

```
char *p="hello";
```

不能修改：

```
p[0]='H';
```

否则可能导致程序崩溃。

---

## 五、全局区

用于存放：

- 全局变量
- 静态变量

例如：

```
int a=10;

static int b=20;
```

程序结束后才释放。

---

## 六、栈区（Stack）

栈区用于存放：

- 局部变量
- 函数参数

例如：

```c
int main()
{

    int a=10;

    return 0;
}
```

变量：

```
a
```

存储在栈区。

特点：

- 自动分配
- 自动释放
- 空间较小

例如：

```c
void fun()
{
    int a=10;
}

int main()
{
    fun();
}
```

当函数结束：

```
a
```

自动销毁。

---

## 七、堆区（Heap）

堆区用于：

> 动态内存分配。

特点：

- 程序员手动申请
- 程序员手动释放
- 空间较大

例如：

```
int *p;

p=(int*)malloc(sizeof(int));
```

申请：

```
堆空间
 |
 ↓
+------+
| 10   |
+------+
```

使用结束：

```
free(p);
```

释放。

---

## 八、栈区和堆区区别

| 区别 | 栈区 | 堆区 |
| --- | --- | --- |
| 管理方式 | 系统管理 | 程序员管理 |
| 生命周期 | 函数结束释放 | free释放 |
| 大小 | 较小 | 较大 |
| 速度 | 快 | 较慢 |
| 使用方式 | 自动创建 | 动态申请 |

---

## 九、为什么需要动态内存？

普通变量：

```
int a;
```

编译时已经确定大小。

数组：

```
int arr[100];
```

大小固定。

但是：

如果用户输入：

```
请输入学生数量：
500
```

程序不知道需要多少空间。

因此需要：

动态内存。

---

## 十、动态内存分配函数

C语言提供：

头文件：

```
#include <stdlib.h>
```

常用函数：

| 函数 | 功能 |
| --- | --- |
| malloc | 申请内存 |
| calloc | 申请并初始化 |
| realloc | 重新调整大小 |
| free | 释放内存 |

---

## 十一、malloc函数

### 1. 函数介绍

malloc：

memory allocation

作用：

> 动态申请一块连续内存。

格式：

```
malloc(字节数);
```

例如：

申请一个int空间：

```
int *p;

p=(int*)malloc(sizeof(int));
```

---

## 十二、malloc使用示例

```c
#include<stdio.h>
#include<stdlib.h>

int main()
{

    int *p;

    p=(int*)malloc(sizeof(int));

    if(p==NULL)
    {
        printf("申请失败\n");

        return -1;
    }

    *p=100;

    printf("%d\n",*p);

    free(p);

    return 0;
}
```

运行：

```
100
```

---

## 十三、malloc注意事项

### 1. 判断申请是否成功

错误：

```
*p=10;
```

如果申请失败：

```
p=NULL;
```

会导致：

空指针访问。

正确：

```
if(p==NULL)
{
    return -1;
}
```

---

### 2. 使用后必须释放

错误：

```
malloc(100);
```

没有保存地址。

导致：

内存泄漏。

正确：

```
free(p);
```

---

## 十四、calloc函数

calloc：

> 申请连续空间，并初始化为0。

格式：

```
calloc(数量,大小);
```

例如：

申请10个int：

```
int *p;

p=(int*)calloc(10,sizeof(int));
```

相当于：

```
malloc(10*sizeof(int));
```

但是：

calloc会初始化。

---

示例：

```c
int *p;

p=(int*)calloc(5,sizeof(int));

for(int i=0;i<5;i++)
{
    printf("%d ",p[i]);
}
```

输出：

```
0 0 0 0 0
```

---

## 十五、realloc函数

### 作用

重新调整动态内存大小。

格式：

```
realloc(原地址,新大小);
```

例如：

原来：

```
int *p;

p=malloc(10*sizeof(int));
```

调整：

```
p=realloc(p,20*sizeof(int));
```

扩大为：

20个int空间。

---

## 十六、free函数

动态申请的内存：

不会自动释放。

必须：

```
free(p);
```

例如：

```
free(p);

p=NULL;
```

推荐释放后：

将指针置NULL。

避免：

野指针。

---

## 十七、内存泄漏

### 什么是内存泄漏？

申请的内存：

没有释放。

例如：

```c
void fun()
{

    int *p;

    p=malloc(100);

}
```

函数结束：

p消失。

但是：

堆空间仍然存在。

这就是：

> 内存泄漏。

---

## 十八、常见内存错误

### 1. 野指针

例如：

```
int *p;

*p=10;
```

p没有指向有效空间。

---

### 2. 空指针访问

例如：

```
int *p=NULL;

*p=100;
```

错误。

---

### 3. 重复释放

例如：

```
free(p);

free(p);
```

可能导致程序异常。

---

### 4. 越界访问

例如：

```
int *p;

p=malloc(5*sizeof(int));

p[10]=100;
```

超过申请范围。

---

## 十九、动态数组实现

普通数组：

```
int arr[10];
```

大小固定。

动态数组：

```
int n;

scanf("%d",&n);

int *arr;

arr=(int*)malloc(n*sizeof(int));
```

用户输入多少：

就申请多少空间。

---

完整代码：

```c
#include<stdio.h>
#include<stdlib.h>

int main()
{

    int n;

    printf("请输入数组大小:");

    scanf("%d",&n);

    int *arr;

    arr=(int*)malloc(n*sizeof(int));

    if(arr==NULL)
    {
        return -1;
    }

    for(int i=0;i<n;i++)
    {
        arr[i]=i;
    }

    for(int i=0;i<n;i++)
    {
        printf("%d ",arr[i]);
    }

    free(arr);

    return 0;
}
```

## 二十、总结

本节主要学习了 C 语言内存管理。

重点内容：

### 1. 内存分区

包括：

- 代码区
- 常量区
- 全局区
- 栈区
- 堆区

### 2. 动态内存函数

#### malloc

```
malloc()
```

申请空间

#### calloc

```
calloc()
```

申请并初始化

#### realloc

```
realloc()
```

调整空间大小

#### free

```
free()
```

释放空间

### 3. 注意事项

动态内存使用原则：

```
申请 → 使用 → 释放
```

否则容易产生：

- 内存泄漏
- 野指针
- 空指针
- 越界访问

内存管理是 C 语言区别于高级语言的重要特点，也是后续学习：

- 链表
- 数据结构
- Linux系统编程
- 嵌入式开发

的重要基础。
