在C语言中，数据类型决定了数据对象的特性。除了系统预设的基础数据类型，我们还可以使用**构造数据类型**，这是一种需要用户自行定义的数据类型。本篇博客将重点带你了解最常用的构造数据类型——结构体（struct），以及它在实际开发中的应用细节。

### 一、 结构体（struct）的基础语法

结构体允许我们将不同类型的数据组合在一起，形成一个新的逻辑整体。

#### 1. 类型定义

结构体的定义需要使用 `struct` 关键字，基本格式如下：

```
struct 结构体名 {
    数据类型1 成员变量1;
    数据类型2 成员变量2;
    数据类型3 成员变量3;
    ...
};
```

#### 2. 变量定义与初始化

定义好类型后，就可以按标准格式（`存储类型 数据类型 变量名;`）来声明结构体变量了。对于结构体的初始化，C语言提供了非常灵活的方式：

- **全部初始化**：严格按照成员变量定义的顺序进行赋值，例如

  ```c
  struct student s = {"zhangsan", 'm', 18, 90};
  ```

- **指定成员初始化**：可以通过 `.` 操作符显式地为特定的成员赋值，例如

  ```c
  struct student s2 = { .name = "zhangsan", .score = 60, };
  ```

### 二、 成员变量的访问

访问结构体内部的数据时，我们需要根据变量的具体类型来选择合适的操作符：

| 变量类型 | 访问操作符 | 核心规则 |
| --- | --- | --- |
| 结构体普通变量 | `.` (点操作符) | 结构体变量类型通过 `.` 访问成员变量。 |
| 结构体指针变量 | `->` (箭头操作符) | 结构体指针类型通过 `->` 访问成员变量。 |

> **重点笔记：** 无论使用 `.` 还是 `->` 访问成员变量，最终表达式的数据类型都是完全由该成员变量自身的类型决定的。

### 三、 结构体的存储与内存对齐（核心机制）

结构体在内存中的存储并不是简单的成员大小相加，而是遵循**内存对齐**的原则。

- **成员对齐规则**：结构体内的每个成员变量，只能存放在内存地址为其自身基本类型长度整数倍的内存单元中。
- **整体大小规则**：整个结构体的总大小，必须是其内部最大基本类型长度的整数倍。
- **手动调整对齐**：在特定场景下，我们可以通过

  ```c
  #pragma pack
  ```

  **(对齐字节数)**来手动调整内存对齐的方式。

### 四、 结构体与函数参数

结构体非常适合作为函数的参数来传递一组强关联的数据。常见的定义及传参声明形式包括：

- **作为返回值**：例如

  ```c
  struct student GetStuInfo(void);
  ```

  函数执行后返回一个完整的结构体变量。

- **值传递**：例如

  ```c
  void PutStuInfo(struct student tmpstu);
  ```

  这会将实参的副本传递给函数。

- **地址传递（指针）**：例如

  ```c
  void PutStuInfoByPoint(struct student *pstu);
  ```

  传递结构体指针通常效率更高，且允许在函数内修改原始数据。

### 五、 其他构造数据类型

除了开发中最常用的结构体（struct）之外，C语言中的构造数据类型还包含以下两种：

- **共用体 (union)**。
- **枚举 (enum)**。
