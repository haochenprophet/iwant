## 前言

在前面的学习中，我们已经学习了数组、字符串以及基本的数据处理方法。随着程序规模不断增大，如果所有代码都写在 `main()` 函数中，会导致程序结构复杂、代码重复，不利于后期维护。

为了提高代码的复用性和可读性，C语言提供了**函数机制**。函数可以将一个完整功能封装起来，在程序中多次调用。

今天主要学习了 C 语言中的**函数定义、函数调用、函数声明、函数参数传递、数组传参、递归函数以及预处理命令**等内容。通过函数封装，可以让程序结构更加清晰，也为后续大型项目开发打下基础。

---

## 一、函数的基本概念

### 1. 什么是函数

函数是一段完成特定功能的代码模块。

使用函数可以：

- 减少重复代码；
- 提高代码复用性；
- 增强程序结构化；
- 方便程序调试和维护。

例如：

如果需要多次计算两个数的和，可以将计算过程封装成一个函数。

---

## 二、函数的三种形式

C语言中函数主要包括：

1. 函数定义
2. 函数调用
3. 函数声明

---

## 三、函数定义

函数定义格式：

```
返回值类型 函数名(参数列表)
{
    函数体;

    return 返回值;
}
```

例如：

```c
#include <stdio.h>

int add(int a,int b)
{
    return a+b;
}
```

其中：

- `int`：返回值类型；
- `add`：函数名；
- `a、b`：函数参数；
- `return`：返回计算结果。

---

## 四、函数调用

函数定义完成后，需要通过函数调用执行。

调用格式：

```
函数名(参数);
```

示例：

```c
#include <stdio.h>

int add(int a,int b)
{
    return a+b;
}

int main()
{
    int result;

    result = add(10,20);

    printf("%d\n",result);

    return 0;
}
```

运行结果：

```
30
```

---

## 五、函数声明

如果函数定义在 `main()` 函数之后，需要提前声明函数。

例如：

```c
#include <stdio.h>

int add(int a,int b);

int main()
{
    printf("%d\n",add(3,5));

    return 0;
}

int add(int a,int b)
{
    return a+b;
}
```

函数声明的作用：

- 告诉编译器函数的返回值类型；
- 告诉编译器函数参数类型；
- 方便函数调用。

---

## 六、函数参数传递

函数之间的数据传递主要有以下几种方式：

- 赋值传递（值传递）
- 全局变量传递
- 数组传递

---

## 1. 赋值传递（值传递）

值传递：

> 实参将值复制给形参，形参只是实参的副本。

特点：

- 修改形参不会影响实参；
- 适合函数内部使用外部变量的值。

示例：

```c
#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("%d\n",a);

    return 0;
}
```

运行结果：

```
10
```

原因：

函数中的 `x` 是 `a` 的副本。

---

## 2. 全局变量传递

全局变量可以在多个函数之间共享数据。

例如：

```c
#include <stdio.h>

int num = 10;

void test()
{
    printf("%d\n",num);
}

int main()
{
    test();

    return 0;
}
```

输出：

```
10
```

但是：

全局变量虽然方便，但会降低程序安全性，因此实际开发中应尽量减少使用。

---

## 七、数组传参

数组传递时，传递的是：

> 数组名和数组长度。

---

### 1. 一维整型数组传参

示例：

```c
#include <stdio.h>

void printArray(int arr[],int len)
{
    int i;

    for(i=0;i<len;i++)
    {
        printf("%d ",arr[i]);
    }
}

int main()
{
    int a[5]={1,2,3,4,5};

    printArray(a,5);

    return 0;
}
```

输出：

```
1 2 3 4 5
```

注意：

数组传递后，函数内部操作的数组和外部数组保持一致。

---

## 八、封装冒泡排序函数

利用数组传参，可以将冒泡排序封装成函数。

```c
#include <stdio.h>

void BubbleSort(int arr[],int len)
{
    int i,j,temp;

    for(i=0;i<len-1;i++)
    {
        for(j=0;j<len-1-i;j++)
        {
            if(arr[j]>arr[j+1])
            {
                temp=arr[j];
                arr[j]=arr[j+1];
                arr[j+1]=temp;
            }
        }
    }
}

int main()
{
    int a[5]={5,3,8,1,2};

    BubbleSort(a,5);

    for(int i=0;i<5;i++)
    {
        printf("%d ",a[i]);
    }

    return 0;
}
```

运行结果：

```
1 2 3 5 8
```

## 九、一维字符数组传参

字符串本质是字符数组，因此也可以通过函数进行处理。

例如：

封装字符串复制函数：

```c
#include <stdio.h>

void MyStrcpy(char dest[],char src[])
{
    int i=0;

    while(src[i]!='\0')
    {
        dest[i]=src[i];
        i++;
    }

    dest[i]='\0';
}

int main()
{
    char str1[32];
    char str2[]="hello";

    MyStrcpy(str1,str2);

    printf("%s\n",str1);

    return 0;
}
```

输出：

```
hello
```

## 十、递归函数

### 1. 什么是递归函数

递归函数：

> 函数在定义过程中调用自身。

例如：

计算阶乘：

[

5!=5×4×3×2×1

]

代码：

```c
#include <stdio.h>

int fun(int n)
{
    if(n==1)
        return 1;

    return n*fun(n-1);
}

int main()
{
    printf("%d\n",fun(5));

    return 0;
}
```

输出：

```
120
```

---

### 递归注意事项

递归函数必须：

1. 有结束条件；
2. 避免过深层次递归。

否则容易造成：

- 无限调用；
- 栈空间不足。

## 十一、预处理命令

C语言在编译之前，会执行预处理操作。

常见预处理命令：

- 宏定义；
- 条件编译；
- 头文件包含。

---

## 十二、宏定义

宏定义格式：

```
#define 宏名 内容
```

例如：

```
#define PI 3.1415926
```

使用：

```
double s;

s=PI*r*r;
```

---

### 宏定义特点

- 宏名通常使用大写；
- 宏只是代码替换；
- 不会进行数据计算。

---

## 十三、带参数宏

例如：

```
#define MAX(a,b) ((a)>(b)?(a):(b))
```

使用：

```c
printf("%d",MAX(10,20));
```

输出：

```
20
```

带参宏和函数区别：

| 对比 | 函数 | 带参宏 |
| --- | --- | --- |
| 参数类型 | 有 | 无 |
| 返回值 | 有 | 无 |
| 执行方式 | 调用 | 代码替换 |
| 效率 | 较低 | 较高 |

---

## 十四、头文件包含

头文件包含：

```
#include <stdio.h>
```

作用：

将头文件内容展开到当前文件中。

头文件通常包含：

- 数据类型定义；
- 全局变量声明；
- 函数声明；
- 宏定义。
