## 一、什么是数组

数组是一组**相同数据类型**元素的集合，在内存中连续存放。

例如，要保存5名同学的成绩：

不用数组：

```
int score1 = 90;
int score2 = 88;
int score3 = 95;
int score4 = 76;
int score5 = 82;
```

使用数组：

```
int score[5];
```

这样只需要一个数组变量，就可以存放5个整数。

数组中的每个数据称为**数组元素**。

---

## 二、一维数组的定义

数组定义格式：

```
数据类型 数组名[元素个数];
```

例如：

```
int num[5];
char name[20];
float score[10];
```

说明：

- 数组下标从 **0** 开始；
- 数组长度定义后不能改变；
- 数组中的所有元素类型必须一致。

例如：

```
下标：

0    1    2    3    4
┌──┬──┬──┬──┬──┐
│10│20│30│40│50│
└──┴──┴──┴──┴──┘
```

---

## 三、数组初始化

### 1、逐个赋值

```c
int num[5] = {10,20,30,40,50};
```

---

### 2、部分初始化

如果初始化的数据不足数组长度，其余元素自动初始化为0。

```c
int num[5]={1,2};
```

数组内容：

```
1 2 0 0 0
```

---

### 3、省略数组长度

```c
int num[] = {10,20,30,40,50};
```

系统自动计算数组大小。

---

## 四、访问数组元素

数组通过下标访问元素。

例如：

```c
#include <stdio.h>

int main()
{
    int num[5] = {10,20,30,40,50};

    printf("%d\n", num[0]);
    printf("%d\n", num[3]);

    return 0;
}
```

运行结果：

```
10
40
```

注意：

数组下标不能越界。

例如：

```
num[5];
```

属于非法访问，可能导致程序出现不可预知的错误。

---

## 五、遍历数组

遍历数组一般使用 `for` 循环。

例如输出数组所有元素：

```c
#include <stdio.h>

int main()
{
    int num[5] = {10,20,30,40,50};

    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", num[i]);
    }

    return 0;
}
```

运行结果：

```
10 20 30 40 50
```

## 六、数组综合练习

### 1、计算数组元素之和

```c
#include <stdio.h>

int main()
{
    int num[5] = {10,20,30,40,50};

    int sum = 0;
    int i;

    for(i = 0; i < 5; i++)
    {
        sum += num[i];
    }

    printf("sum = %d\n", sum);

    return 0;
}
```

运行结果：

```
sum = 150
```

---

### 2、求数组最大值

```c
#include <stdio.h>

int main()
{
    int num[5]={18,25,7,39,20};

    int max = num[0];
    int i;

    for(i = 1; i < 5; i++)
    {
        if(num[i] > max)
        {
            max = num[i];
        }
    }

    printf("最大值：%d\n", max);

    return 0;
}
```

运行结果：

```
最大值：39
```

---

### 3、统计及格人数

```c
#include <stdio.h>

int main()
{
    int score[8] = {65,78,92,45,80,56,90,73};

    int count = 0;
    int i;

    for(i = 0; i < 8; i++)
    {
        if(score[i] >= 60)
        {
            count++;
        }
    }

    printf("及格人数：%d\n", count);

    return 0;
}
```

运行结果：

```
及格人数：6
```

## 七、数组使用注意事项

学习数组时需要注意以下几点：

- 数组元素类型必须一致；
- 数组下标从 **0** 开始；
- 数组长度定义后不能修改；
- 不要访问越界元素；
- 遍历数组时通常使用 `for` 循环。
