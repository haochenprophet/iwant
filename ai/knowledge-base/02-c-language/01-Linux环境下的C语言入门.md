## 前言

经过前一天学习 Linux 基本命令后，今天正式进入 **C语言开发**。在 Linux 环境下，一个 C 程序从源代码到最终能够运行，需要经过 **预处理、编译、汇编、链接** 四个阶段。同时，也学习了 C 语言中的基本数据类型、进制转换以及常量与变量等基础知识。

---

## 一、GCC编译流程

很多初学者认为执行一条命令：

```bash
gcc hello.c -o hello
```

程序就编译完成了。

实际上，GCC 在后台完成了 **四个步骤**：

```
hello.c
   │
   ▼
① 预处理
   │
   ▼
② 编译
   │
   ▼
③ 汇编
   │
   ▼
④ 链接
   │
   ▼
hello（可执行程序）
```

---

### 1. 预处理（Preprocessing）

预处理主要负责处理所有以 `#` 开头的预处理指令。

例如：

```
#include <stdio.h>
#define MAX 100
```

主要工作包括：

- 展开头文件 (`#include`)
- 替换宏定义 (`#define`)
- 条件编译（`#ifdef`、`#ifndef`、`#if` 等）
- 删除注释

生成预处理文件：

```bash
gcc -E hello.c -o hello.i
```

得到：

```
hello.i
```

此时可以发现，头文件中的内容已经全部展开。

---

### 2. 编译（Compile）

编译器开始检查 C 语言语法，并将 C 代码转换为 **汇编代码**。

命令：

```bash
gcc -S hello.i -o hello.s
```

生成：

```
hello.s
```

汇编代码类似：

```
movl $0,%eax
ret
```

这一步主要负责：

- 语法检查
- 类型检查
- 优化代码
- 生成汇编程序

---

### 3. 汇编（Assemble）

将汇编代码转换成机器能够识别的二进制目标文件。

命令：

```bash
gcc -c hello.s -o hello.o
```

生成：

```
hello.o
```

注意：

> `.o` 文件并不能直接运行，它只是目标文件。

---

### 4. 链接（Link）

最后一步就是链接。

命令：

```bash
gcc hello.o -o hello
```

或者直接：

```bash
gcc hello.c -o hello
```

链接器会把：

- 自己编写的代码
- 标准库
- 系统库

全部连接起来，生成最终可执行程序。

运行：

```bash
./hello
```

输出：

```
Hello World!
```

---

## 二、为什么需要链接？

例如：

```c
printf("Hello World");
```

我们并没有写 `printf()` 的实现。

因为：

> `printf()` 已经存在于 C 标准库中，链接阶段会自动把对应的库函数加入程序。

因此：

> **链接的作用就是把程序所需要的各种目标文件和库文件组合成一个完整的可执行程序。**

---

## 三、程序在计算机中的运行过程

很多初学者认为：

> 写好代码就能运行。

实际上程序运行流程如下：

```
编写代码
    │
    ▼
保存在磁盘
    │
    ▼
GCC编译
    │
    ▼
生成可执行程序
    │
    ▼
运行程序
    │
    ▼
CPU从内存读取指令
    │
    ▼
执行结束
```

需要注意：

- 源代码存放在硬盘中；
- 执行程序时，会加载到内存；
- CPU 从内存读取指令执行；
- 程序结束后，内存会被释放。

## 四、计算机中的数据单位

计算机只能识别 **0 和 1**。

常见单位如下：

| 单位 | 换算关系 |
| --- | --- |
| bit（位） | 最小存储单位 |
| Byte（字节） | 1 Byte = 8 bit |
| KB | 1024 Byte |
| MB | 1024 KB |
| GB | 1024 MB |
| TB | 1024 GB |

例如：

```
1KB = 1024B
1MB = 1024KB
```

## 五、常见进制

计算机中常见四种进制。

### 二进制

只有：

```
0 1
```

例如：

```
101101
```

---

### 八进制

数字：

```
0~7
```

例如：

```
075
```

---

### 十进制

最常见：

```
0~9
```

例如：

```
123
```

---

### 十六进制

数字：

```
0~9
A~F
```

例如：

```
0x2F
```

## 六、C语言基本数据类型

数据类型决定：

> **数据占多少内存，以及能够存储什么数据。**

常见数据类型如下：

| 类型 | 说明 |
| --- | --- |
| short | 短整型 |
| int | 整型 |
| long | 长整型 |
| float | 单精度浮点型 |
| double | 双精度浮点型 |
| char | 字符型 |
| bool | 布尔类型 |
| void | 空类型 |

---

### 1、整型

例如：

```
int age = 20;
```

Linux 64 位环境：

| 类型 | 大小 |
| --- | --- |
| short | 2 Byte |
| int | 4 Byte |
| long | 8 Byte |

---

### 2、浮点型

```
float score = 98.5f;
double pi = 3.1415926;
```

区别：

| 类型 | 大小 | 有效数字 |
| --- | --- | --- |
| float | 4 Byte | 6~8 位 |
| double | 8 Byte | 12~16 位 |

---

### 3、字符型

```
char ch = 'A';
```

字符实际上保存的是 **ASCII 码**。

例如：

```
'A' -> 65
'a' -> 97
'0' -> 48
```

因此：

```c
printf("%d",'A');
```

输出：

```
65
```

---

### 4、布尔类型

```
bool flag = true;
```

C语言中：

```
true  = 1
false = 0
```

实际上：

> **非0即真，0为假。**

---

### 5、void类型

主要用于：

- 空返回值函数
- 指针
- 泛型参数

例如：

```
void test()
{
}
```

---

## 七、常量与变量

### 常量

程序运行过程中不会改变。

例如：

```
100
3.14
'A'
"Hello"
```

还可以使用宏定义：

```
#define MAX 100
```

宏定义本质是**文本替换**，不会进行计算。

建议：

```
#define PI (3.1415926)
```

养成加括号的习惯，避免表达式优先级导致的问题。

---

### 变量

变量表示程序运行过程中可以改变的数据。

例如：

```
int age = 20;
age = 21;
```

变量必须先定义，再使用。
