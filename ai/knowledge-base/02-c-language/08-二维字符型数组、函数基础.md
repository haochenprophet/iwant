## 一、二维字符型数组

### 1. 为什么需要二维字符型数组

在 C 语言中，字符串本质上是字符数组。

例如：

```
char name[20];
```

只能存储一个字符串：

```
Tom
```

如果需要保存多个字符串：

```
Tom
Jack
Lucy
Mary
```

就需要使用二维字符数组。

二维字符数组可以理解为：

> 一个数组中存放多个一维字符数组。

---

## 二、二维字符型数组定义

二维字符数组定义格式：

```
char 数组名[字符串数量][字符串长度];
```

例如：

```
char name[4][20];
```

表示：

- 可以存储4个字符串；
- 每个字符串最大长度为19个字符；
- 最后一个位置用于存放字符串结束符 `\0`。

二维字符数组结构：

```
name[0]  -> "Tom"
name[1]  -> "Jack"
name[2]  -> "Lucy"
name[3]  -> "Mary"
```

---

## 三、二维字符型数组初始化

### 1. 使用字符串初始化

最常用的方法：

```c
#include <stdio.h>

int main()
{
    char name[4][20] =
    {
        "Tom",
        "Jack",
        "Lucy",
        "Mary"
    };

    return 0;
}
```

系统会自动在每个字符串末尾添加：

```
'\0'
```

表示字符串结束。

---

### 2. 使用字符形式初始化

```c
char str[2][6] =
{
    {'h','e','l','l','o','\0'},
    {'w','o','r','l','d','\0'}
};
```

这种方式需要手动添加字符串结束符。

---

## 四、二维字符型数组访问

二维字符数组访问方式：

```
数组名[行][列]
```

例如：

```c
char name[2][10] =
{
    "hello",
    "linux"
};
```

访问：

```
name[0]
```

表示：

```
hello
```

访问：

```
name[0][1]
```

表示：

```
e
```

---

## 五、二维字符数组案例

### 输出多个字符串

```c
#include <stdio.h>

int main()
{
    char name[4][20] =
    {
        "Tom",
        "Jack",
        "Lucy",
        "Mary"
    };

    int i;

    for(i = 0; i < 4; i++)
    {
        printf("%s\n", name[i]);
    }

    return 0;
}
```

运行结果：

```
Tom
Jack
Lucy
Mary
```

通过循环遍历二维字符数组，可以方便地处理多个字符串。

## 六、C语言函数基础

### 1. 为什么使用函数

当程序功能越来越复杂时，如果所有代码都写在 `main()` 函数中，会导致：

- 程序结构混乱；
- 代码重复；
- 不方便维护。

函数可以将一个功能封装起来，提高代码复用性。

函数的优点：

- 减少重复代码；
- 提高程序可读性；
- 方便模块化开发。

---

## 七、函数定义

函数基本格式：

```
返回值类型 函数名(参数列表)
{
    函数体;

    return 返回值;
}
```

例如：

```c
#include <stdio.h>

int add(int a,int b)
{
    return a+b;
}

int main()
{
    int ret;

    ret = add(10,20);

    printf("%d\n",ret);

    return 0;
}
```

运行结果：

```
30
```

---

## 八、函数参数传递

函数调用时：

```
add(10,20);
```

其中：

```
10、20
```

称为实际参数。

函数定义：

```
int add(int a,int b)
```

其中：

```
a、b
```

称为形式参数。

函数调用时，会把实参的值传递给形参。

---

## 九、变量定义与表达式运算

C语言中变量需要先定义，再使用。

例如：

```
int a;
double b;
char c;
```

不同变量类型占用的存储空间不同。

常见数据类型：

| 类型 | 说明 |
| --- | --- |
| int | 整型 |
| float | 单精度浮点型 |
| double | 双精度浮点型 |
| char | 字符型 |
