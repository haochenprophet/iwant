## 一、GCC编译流程

在 Linux 中，一个 C 程序从源码到可执行文件需要经过四个阶段。

```
hello.c
   │
   ▼
预处理（Preprocess）
   │
   ▼
编译（Compile）
   │
   ▼
汇编（Assemble）
   │
   ▼
链接（Link）
   │
   ▼
hello
```

对应命令如下：

#### 1. 预处理

```bash
gcc -E hello.c -o hello.i
```

主要完成：

- 展开头文件
- 宏替换
- 条件编译

例如：

```
#include <stdio.h>

#define MAX 100
```

都会在预处理阶段完成替换。

---

#### 2. 编译

```bash
gcc -S hello.c -o hello.s
```

将 C 代码转换成汇编代码。

---

#### 3. 汇编

```bash
gcc -c hello.c -o hello.o
```

生成目标文件（Object File）。

---

#### 4. 链接

```bash
gcc hello.c -o hello
```

生成最终可执行程序。

运行程序：

```bash
./hello
```

## 二、C语言基本数据类型

C语言的数据类型决定了变量能够存储的数据种类以及占用内存大小。

主要分为：

```
数据类型
│
├──整数
├──浮点数
├──字符
├──布尔
└──void
```

---

### 1、整数类型

| 类型 | 大小 |
| --- | --- |
| short | 2字节 |
| int | 4字节 |
| long | 8字节 |

例如：

```
short a;
int b;
long c;
```

还可以分为

```
signed int
unsigned int
```

unsigned 不能表示负数，但是能表示更大的正整数。

---

### 2、浮点数类型

包括：

```
float
double
```

示例：

```
float a = 3.14f;

double b = 3.1415926;
```

其中：

- float：4字节
- double：8字节

double 精度更高。

---

### 3、字符类型

字符类型只有一个：

```
char
```

例如：

```
char ch='A';
```

实际上字符在计算机内部保存的是 ASCII 码。

例如：

```
'A' -> 65

'a' -> 97
```

因此：

```c
printf("%d", 'A');
```

输出

```
65
```

---

### 4、布尔类型

需要包含头文件

```
#include <stdbool.h>
```

定义：

```
bool flag=true;
```

只有两个值：

```
true
false
```

---

### 5、void类型

void 表示"无类型"。

例如：

```
void func()
{

}
```

或者

```
void *p;
```

---

## 三、常量与变量

### 常量

程序运行过程中不会发生改变。

例如：

```
100

3.14

'A'

"hello"
```

也可以利用宏定义：

```
#define PI 3.1415926
```

宏不会占用内存，仅仅是文本替换。

---

### 变量

变量用于保存程序运行过程中的数据。

定义格式：

```
数据类型 变量名;
```

例如：

```
int age;

float score;

char ch;
```

建议变量定义时立即初始化：

```
int num=0;
```

否则变量中可能保存随机值。

---

## 四、变量命名规范

变量名应遵循以下原则：

✅ 可以使用：

```
student

maxScore

temp_num
```

不能使用：

```
1abc

printf

int
```

推荐采用：

- 驼峰命名

```
studentScore
```

或者

- 下划线命名

```
student_score
```

提高代码可读性。

---

## 五、类型转换

混合类型计算时，系统会自动进行类型转换。

例如：

```c
int a=5;

double b=3.5;

printf("%lf",a+b);
```

输出：

```
8.500000
```

这里 int 自动转换成 double。

---

也可以进行强制类型转换：

```
(int)3.14
```

结果：

```
3
```

小数部分被舍弃。

---

## 六、常见运算符

### 算术运算符

| 运算符 | 功能 |
| --- | --- |
| + | 加 |
| - | 减 |
| * | 乘 |
| / | 除 |
| % | 取余 |

例如：

```c
int a=10;
int b=3;

printf("%d",a%b);
```

输出：

```
1
```

---

### 自增、自减

```
a++

++a
```

区别：

```
a++

先使用
后加1
++a

先加1
后使用
```

这是初学者容易出错的地方。

---

### 赋值运算符

除了

```
=
```

还有

```
+=

-=

*=

/=

%=
```

例如：

```
a+=5;
```

等价于：

```
a=a+5;
```

---

### sizeof运算符

查看变量占用字节数。

例如：

```c
int a;

printf("%d",sizeof(a));
```

输出：

```
4
```

---

## 七、输入输出函数

需要头文件：

```
#include <stdio.h>
```

---

### printf()

输出函数

例如：

```c
printf("Hello World\n");
```

---

### scanf()

输入函数

例如：

```
int a;

scanf("%d",&a);
```

---

### getchar()

读取一个字符

```
char ch;

ch=getchar();
```

---

### putchar()

输出一个字符

```
putchar('A');
```

输出：

```
A
```

---

示例：输入一个小写字母，输出对应的大写字母。

```c
#include <stdio.h>

int main()
{
    char ch;

    ch=getchar();

    putchar(ch-32);

    return 0;
}
```

运行：

```
输入：

a

输出：

A
```
