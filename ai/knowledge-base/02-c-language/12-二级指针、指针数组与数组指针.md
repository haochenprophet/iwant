## 前言

在前面的学习中，我们已经掌握了 C 语言中一级指针的基本使用，了解了指针变量保存地址的特点，并学习了指针作为函数参数、数组与指针之间的关系。

指针是 C 语言区别于其他高级语言的重要特性，它能够直接访问内存地址，提高程序运行效率。

但是在实际编程过程中，有时不仅需要操作变量，还需要操作**指针变量本身**。例如：修改函数外部的指针；管理多个字符串处理多级数据结构。这时就需要使用 **二级指针**。

---

## 一、二级指针

### 1. 一级指针回顾

一级指针：

> 存储变量地址的变量。

例如：

```c
#include <stdio.h>

int main()
{
    int a = 10;

    int *p;

    p = &a;

    printf("%d\n",*p);

    return 0;
}
```

运行结果：

```
10
```

其中：

```
p=&a;
```

表示：

指针 `p` 保存变量 `a` 的地址。

---

## 二、什么是二级指针

二级指针：

> 存储一级指针地址的指针。

定义方式：

```
数据类型 **指针变量名;
```

例如：

```
int **pp;
```

表示：

`pp` 是一个二级整型指针。

---

### 二级指针关系图

```
 a
 |
10

 ↑
 |
 p

 ↑
 |
 pp
```

其中：

- `a` 保存数据；
- `p` 保存 `a` 的地址；
- `pp` 保存 `p` 的地址。

---

## 三、二级指针使用

示例：

```c
#include <stdio.h>

int main()
{
    int a=10;

    int *p=&a;

    int **pp=&p;

    printf("a=%d\n",a);

    printf("*p=%d\n",*p);

    printf("**pp=%d\n",**pp);

    return 0;
}
```

运行结果：

```
a=10
*p=10
**pp=10
```

分析：

一级指针：

```
*p
```

访问变量 `a`。

二级指针：

```
**pp
```

通过：

```
pp → p → a
```

最终访问变量 `a`。

---

## 四、利用二级指针修改数据

示例：

```c
#include <stdio.h>

int main()
{
    int a=10;

    int *p=&a;

    int **pp=&p;

    **pp=100;

    printf("%d\n",a);

    return 0;
}
```

输出：

```
100
```

执行过程：

```
pp
 |
 ↓
p
 |
 ↓
a
```

通过二级指针最终修改变量 `a`。

---

## 五、二级指针作为函数参数

### 1. 为什么需要二级指针

之前学习一级指针传参：

```
void fun(int *p)
```

可以修改普通变量。

例如：

```c
void change(int *p)
{
    *p=100;
}
```

但是如果想修改一个指针变量：

```
char *str;
```

一级指针无法完成。

需要传递：

```
char **str;
```

---

## 六、通过二级指针修改指针

示例：

```c
#include <stdio.h>

void change(char **p)
{
    *p="Linux";
}

int main()
{
    char *str="hello";

    change(&str);

    printf("%s\n",str);

    return 0;
}
```

运行结果：

```
Linux
```

分析：

调用：

```
change(&str);
```

传入的是：

```
str的地址
```

函数内部：

```
*p
```

代表：

```
str
```

因此可以修改指针指向的位置。

---

## 七、指针数组

### 1. 指针数组概念

指针数组：

> 数组中的每个元素都是指针。

定义：

```
数据类型 *数组名[数组大小];
```

例如：

```
int *p[5];
```

表示：

有5个元素，每个元素都是 `int *` 类型。

---

## 八、指针数组使用

示例：

```c
#include <stdio.h>

int main()
{
    int a=10;
    int b=20;
    int c=30;

    int *p[3];

    p[0]=&a;
    p[1]=&b;
    p[2]=&c;

    printf("%d\n",*p[0]);

    printf("%d\n",*p[1]);

    printf("%d\n",*p[2]);

    return 0;
}
```

输出：

```
10
20
30
```

---

## 九、指针数组存储字符串

二维字符数组：

```
char name[3][20];
```

也可以使用指针数组：

```
char *name[3];
```

示例：

```c
#include <stdio.h>

int main()
{
    char *name[3]=
    {
        "Tom",
        "Jack",
        "Lucy"
    };

    for(int i=0;i<3;i++)
    {
        printf("%s\n",name[i]);
    }

    return 0;
}
```

输出：

```
Tom
Jack
Lucy
```

## 十、数组指针

### 1. 什么是数组指针

数组指针：

> 指向数组的指针。

定义：

```
数据类型 (*指针变量名)[数组长度];
```

例如：

```
int (*p)[5];
```

表示：

`p` 指向一个包含5个整数的数组。

---

## 十一、指针数组和数组指针区别

这是 C 语言中容易混淆的知识点。

| 类型 | 定义 | 含义 |
| --- | --- | --- |
| 指针数组 | `int *p[5]` | 存放指针的数组 |
| 数组指针 | `int (*p)[5]` | 指向数组的指针 |

区别：

### 指针数组

重点：

```
数组
里面存放指针
```

---

### 数组指针

重点：

```
指针
指向数组
```

---

## 十二、数组指针访问二维数组

例如：

```c
#include <stdio.h>

int main()
{
    int a[2][3]=
    {
        {1,2,3},
        {4,5,6}
    };

    int (*p)[3];

    p=a;

    printf("%d\n",p[1][2]);

    return 0;
}
```

输出：

```
6
```
