## 一、指针作为函数参数

在之前学习函数参数传递时，了解到普通参数采用的是**值传递**。

### 1. 值传递

值传递：

> 实参将自己的值复制一份传递给形参。

特点：

- 形参改变不会影响实参；
- 只能读取外部变量的值。

例如：

```c
#include <stdio.h>

void change(int num)
{
    num = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("%d\n",a);

    return 0;
}
```

输出：

```
10
```

原因：

函数内部的 `num` 只是 `a` 的副本。

---

### 2. 地址传递

如果希望在函数内部修改外部变量，需要传递变量地址。

例如：

```c
#include <stdio.h>

void change(int *p)
{
    *p = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("%d\n",a);

    return 0;
}
```

运行结果：

```
100
```

原因：

函数接收的是变量地址，通过：

```
*p
```

修改了原变量。

因此：

- 使用值传递：函数内部使用外部变量值；
- 使用地址传递：函数内部修改外部变量。

---

## 二、利用地址传递实现多个返回值

普通函数只能通过 `return` 返回一个值。

例如：

```c
int fun()
{
    return 10;
}
```

如果需要同时返回多个结果，可以利用指针参数。

例如：

计算两个数的和与差：

```c
#include <stdio.h>

void Calculate(int a,int b,int *sum,int *sub)
{
    *sum=a+b;

    *sub=a-b;
}

int main()
{
    int sum;
    int sub;

    Calculate(20,10,&sum,&sub);

    printf("sum=%d\n",sum);

    printf("sub=%d\n",sub);

    return 0;
}
```

输出：

```
sum=30
sub=10
```

## 三、一维数组与指针的关系

C语言中：

> 数组名本质上是指向数组第一个元素的指针常量。

例如：

```c
int a[5]={1,2,3,4,5};
```

数组名：

```
a
```

等价于：

```
&a[0]
```

可以：

```
int *p;

p=a;
```

也可以：

```
p=&a[0];
```

---

## 四、数组下标与指针运算

数组访问：

```
a[n]
```

等价于：

```
*(a+n)
```

如果：

```
int *p=a;
```

那么：

```
a[n]
```

也等价于：

```
*(p+n)
```

还可以写：

```
p[n]
```

例如：

```c
#include <stdio.h>

int main()
{
    int a[5]={10,20,30,40,50};

    int *p=a;

    printf("%d\n",*(p+2));

    return 0;
}
```

输出：

```
30
```

## 五、一维数组传参

数组作为函数参数时，可以有多种写法。

例如：

```
int fun(int array[],int len);
```

也可以写：

```
int fun(int *parray,int len);
```

两种方式效果相同。

---

### 示例：封装数组输出函数

```c
#include <stdio.h>

void OutputArray(int *p,int len)
{
    int i;

    for(i=0;i<len;i++)
    {
        printf("%d ",p[i]);
    }
}

int main()
{
    int a[5]={1,2,3,4,5};

    OutputArray(a,5);

    return 0;
}
```

输出：

```
1 2 3 4 5
```

## 六、一维字符数组传参

字符串本质也是字符数组，因此可以通过指针传递。

例如：

```c
#include <stdio.h>

void PrintString(char *p)
{
    while(*p!='\0')
    {
        printf("%c",*p);

        p++;
    }
}

int main()
{
    char str[]="hello";

    PrintString(str);

    return 0;
}
```

输出：

```
hello
```

## 七、利用指针实现 mystrlen

不使用：

```
strlen()
```

实现字符串长度统计。

思路：

利用指针不断向后移动。

代码：

```c
#include <stdio.h>

int MyStrlen(char *p)
{
    int len=0;

    while(*p!='\0')
    {
        len++;

        p++;
    }

    return len;
}

int main()
{
    char str[]="hello";

    printf("%d\n",MyStrlen(str));

    return 0;
}
```

输出：

```
5
```

## 八、指针函数

### 1. 概念

指针函数：

> 本质是函数，函数返回值是指针类型。

例如：

```
int *fun(int x,int y);
```

表示：

函数返回一个 `int *` 类型的数据。

---

### 注意

指针函数：

不能返回局部变量地址。

错误示例：

```c
int *fun()
{
    int a=10;

    return &a;
}
```

原因：

函数结束后，局部变量空间被释放。

---

正确：

返回动态申请空间或者全局变量地址。

---

## 九、函数指针

### 1. 概念

函数指针：

> 本质是指针，指针指向一个函数。

例如：

定义函数：

```c
int add(int a,int b)
{
    return a+b;
}
```

定义函数指针：

```
int (*p)(int,int);
```

让指针指向函数：

```
p=add;
```

调用：

```c
printf("%d",p(10,20));
```

输出：

```
30
```

## 十、const指针

const表示：

> readonly（只读）。

C语言中常见const指针有三种形式。

---

### 1. 指向常量的指针

```
const int *p;
```

或者：

```
int const *p;
```

特点：

- 指针可以修改；
- 指向的数据不能修改。

例如：

```
int a=10;

const int *p=&a;

*p=20;   //错误
```

---

### 2. 常量指针

```
int *const p=&a;
```

特点：

- 指针不能改变；
- 指向的数据可以修改。

例如：

```
*p=20;
```

正确。

---

### 3. 指向常量的常量指针

```
const int *const p=&a;
```

特点：

- 指针不能改变；
- 指向的数据也不能修改。
