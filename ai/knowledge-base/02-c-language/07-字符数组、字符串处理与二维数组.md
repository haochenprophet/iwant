## **前言**

经过前面对一维整型数组的学习，能够使用数组存储和处理多个相同类型的数据。本节课程进一步学习了**字符数组和字符串**，了解了 C 语言中字符串的存储方式，以及常用的字符串处理函数。同时，还初步学习了**二维数组**的定义与初始化，为后续学习矩阵运算和复杂数据存储打下基础。

---

## 一、字符数组与字符串

在 C 语言中，并没有专门的字符串类型，字符串实际上是**以 '\0' 结尾的字符数组**。

例如：

```
char str[6] = "hello";
```

它在内存中的存储如下：

```
h   e   l   l   o   \0
```

因此，在定义字符数组时，要预留一个位置存放字符串结束标志 `'\0'`。

---

## 二、字符串初始化

字符串初始化有多种方式。

#### 方法一

```
char str[] = "hello";
```

#### 方法二

```c
char str[6] = {'h','e','l','l','o','\0'};
```

#### 方法三

```
char str[20] = "hello";
```

其中第一种方式最常用，也是最简洁的写法。

---

## 三、字符串输出

输出字符串有两种常见方式。

### printf()

```c
#include <stdio.h>

int main()
{
    char str[] = "Hello Linux";

    printf("%s\n", str);

    return 0;
}
```

运行结果：

```
Hello Linux
```

---

### puts()

```c
#include <stdio.h>

int main()
{
    char str[] = "Hello Linux";

    puts(str);

    return 0;
}
```

运行结果：

```
Hello Linux
```

需要注意的是，**puts() 会自动在字符串末尾添加一个换行符**，而 `printf()` 是否换行需要自己添加 `\n`。

---

## 四、字符串输入

课堂介绍了两种字符串输入方式。

### scanf()

```
char str[30];

scanf("%s", str);
```

这种方式读取字符串时，以空格作为结束标志。

---

### gets()

```
char str[30];

gets(str);
```

`gets()` 可以读取带空格的一整行内容，但由于没有长度检查，存在安全隐患，因此现代开发中通常推荐使用 `fgets()` 代替。

---

## 五、常用字符串处理函数

C 语言提供了多个字符串处理函数，使用时需要包含头文件：

```
#include <string.h>
```

---

### 1、strlen()——求字符串长度

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[] = "hello";

    printf("长度=%d\n", strlen(str));

    return 0;
}
```

输出：

```
长度=5
```

需要注意：

- `strlen()` 统计的是字符串长度，不包括 `'\0'`。
- `sizeof()` 返回的是整个数组占用的字节数，两者不能混淆。

---

### 2、strcpy()——字符串复制

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[30];

    strcpy(str, "Hello World");

    printf("%s\n", str);

    return 0;
}
```

运行结果：

```
Hello World
```

目标数组必须足够大，否则容易发生越界。

---

### 3、strcat()——字符串拼接

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str1[30] = "Hello ";
    char str2[] = "Linux";

    strcat(str1, str2);

    printf("%s\n", str1);

    return 0;
}
```

运行结果：

```
Hello Linux
```

拼接后的字符串不能超过目标数组容量。

---

### 4、strcmp()——字符串比较

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str1[] = "apple";
    char str2[] = "banana";

    printf("%d\n", strcmp(str1, str2));

    return 0;
}
```

返回值说明：

- 返回 **0**：两个字符串相等；
- 返回 **大于0**：第一个字符串大于第二个字符串；
- 返回 **小于0**：第一个字符串小于第二个字符串。

## 六、课堂练习——统计字符串长度（不使用 strlen）

为了进一步理解字符串的存储方式，课堂要求不使用 `strlen()` 自己实现字符串长度统计。

```c
#include <stdio.h>

int main()
{
    char str[100];
    int len = 0;

    gets(str);

    while(str[len] != '\0')
    {
        len++;
    }

    printf("字符串长度：%d\n", len);

    return 0;
}
```

通过遍历字符数组，直到遇到字符串结束符 `'\0'`，即可得到字符串长度。

## 七、二维数组初识

二维数组可以理解为**由多个一维数组组成的数组**，常用于表示矩阵、成绩表等二维数据。

二维数组定义格式：

```
数据类型 数组名[行数][列数];
```

例如：

```
int a[2][3];
```

初始化方式：

```c
int a[2][3] =
{
    {1,2,3},
    {4,5,6}
};
```

输出二维数组：

```c
#include <stdio.h>

int main()
{
    int a[2][3] =
    {
        {1,2,3},
        {4,5,6}
    };

    int i,j;

    for(i=0;i<2;i++)
    {
        for(j=0;j<3;j++)
        {
            printf("%d ",a[i][j]);
        }

        printf("\n");
    }

    return 0;
}
```

运行结果：

```
1 2 3
4 5 6
```
