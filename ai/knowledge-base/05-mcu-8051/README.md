# 05 · 单片机学习笔记（STC89C52）

> 原文出处：CSDN「斑马819」《单片机学习笔记》系列，共 2 篇，发布于 2026-09-15 至 2026-09-16。

## 一、系列定位

这是两篇从零上手 51 单片机的实践笔记，平台是 STC89C52（8051 内核，8 位）。作者没有先铺开体系，而是按“点一个灯 → 显示一个数 → 定一个时 → 响应一次按键 → 收发一个字节 → 读一个温度”的顺序推进。

- **视角**：原文反复强调，Linux C 程序操作的是操作系统提供的资源，单片机程序则直接控制硬件寄存器；本系列补的正是“直接控制硬件”这一课。
- **写法**：每个外设先讲原理（电平、段码、时序），再给最小可运行代码，最后做模块化整理。
- **范围**：只覆盖 STC89C52 的片内资源与两种片外器件（数码管、DS18B20），不涉及 RTOS、Bootloader 或网络。
- **适合**：有 C 语言基础、准备学嵌入式、但还没写过裸机程序的人。

## 二、前置知识与环境

- **内核基础**：8051 内核，8 位数据总线；片内 4 组 8 位 IO 口 P0～P3，以及定时器、中断、串口等外设。
- **开发环境**：Keil C51，通过 `#include <reg52.h>` 引入片内寄存器和 IO 口定义。
- **语言基础**：C 语言函数、位运算（`~`、`&`、`|`）、数组、指针与字符串遍历；能分清 `unsigned char` 与 `unsigned int`。
- **硬件**：一块 STC89C52 开发板（LED 接 P2 且低电平点亮、段码由 P0 输出、多位数码管、按键接 INT0、DS18B20 的 DQ 接 P3.7），以及一个 USB 转 TTL 模块用于连接 PC。
- **工程组织**：按 `main.c` + `digitaltube.c/h` + `delay.c/h` 拆分，头文件放声明，`.c` 放实现。

## 三、知识脉络

主线是一条从“输出”走向“通信”的链：先用 GPIO（General Purpose Input/Output，通用输入输出接口）驱动 LED（Light Emitting Diode，发光二极管）和数码管，再用定时器与中断摆脱软件延时，最后用 UART（Universal Asynchronous Receiver/Transmitter，串行异步收发器）和单总线与外部设备通信。

```text
GPIO → LED（低电平有效）→ 软件延时 → 流水灯
   ↓
数码管（a~g + dp）：段码表 → 位选 / 段选 → 动态扫描 → 模块化
   ↓
定时器 Timer0/Timer1（TMOD、TH0/TL0、TR0、TF0）→ 溢出
   ↓
中断（IE、EA、EX0、IT0）→ 外部中断 INT0 → 中断服务函数
   ↓
UART（SCON、SBUF、TI）→ 与 PC 通信
   ↓
DS18B20 单总线（复位、0xCC、0x44、0xBE、读 2 字节）
```

这条链路有两个转折：一是从“CPU 空转延时”转到“硬件定时 + 中断响应”，二是从“单片机自己输出”转到“按协议与外部器件对话”。前一篇打显示与中断的地基，后一篇把通信拆成 UART（单片机之间、单片机与 PC）和单总线（单片机与传感器）两条线。

## 五、核心要点

### 5.1 GPIO 与 LED

- **四组 IO**：`P0`、`P1`、`P2`、`P3` 各 8 位（如 `P2.0`～`P2.7`）。整组写用 `P2 = 0xFF;`，单独一位用 `P2^0 = 0;`。
- **低电平有效**：本系列开发板上 LED 接 P2，输出 0 亮、输出 1 灭，所以初始化写 `P2 = 0xFF` 让灯全灭。
- **取反封装**：`led_on(0x01)` 点亮第 1 个 LED，函数体为 `P2 = ~on;`；传 `0x05`（`0000 0101`）则输出 `1111 1010`，点亮对应两位。
- **流水灯**：核心是不断改写 P2，`0xFE` → `0xFD` → `0xFB` → `0xF7`，每次挪动一个 0；必须配延时，原文用 `while(t--);` 实现 `delay(0x3FFF)`，否则变化快到人眼看不见。

```c
void led_init(void) { P2 = 0xFF; }
void led_on(unsigned char on) { P2 = ~on; }
```

### 5.2 数码管与动态扫描

- **结构**：数码管由 a、b、c、d、e、f、g 七段加小数点 dp 组成，显示数字就是控制这几段的亮灭。
- **段码表**：原文给出 0～9 的段码 `0x3F`、`0x06`、`0x5B`、`0x4F`、`0x66`、`0x6D`、`0x7D`、`0x07`、`0x7F`、`0x6F`，例如 `P0 = 0x06;` 显示 1。
- **位选与段选**：位选决定“亮哪一位”，段选决定“显示什么”；原文的扫描顺序是先选位、再送段码。
- **动态扫描**：4 位数码管显示 1234，实际是一位一位轮流点亮（第 1 位显示 1 → 第 2 位显示 2 → … → 回到第 1 位），扫描足够快时人眼看到的就是完整的 1234。
- **模块化**：`digitaltube.h` 暴露 `digitaltube_init`、`bit_select`、`seg_select`、`display_num`，主函数只负责初始化和 `while (1) { display_num(num++); delay(0x3FFF); }`，细节沉到 `.c` 文件。

### 5.3 定时器与中断

- **为什么用**：`while(t--)` 是软件延时，CPU 全程空转；定时器用片内硬件计数，可用于定时、LED 闪烁、数码管扫描和串口波特率产生。
- **寄存器**：`TMOD` 选工作模式；`TH0`/`TL0`、`TH1`/`TL1` 是高低 8 位初值；`TR0`/`TR1` 启动；`TF0`/`TF1` 是溢出标志。Timer0 可工作在 16 位模式，原文示例初值 `TH0 = 0x4C; TL0 = 0x00;`。
- **查询与中断**：不用中断时可以 `while(TF0 == 0);` 死等溢出；用中断则让溢出打断主程序，执行完再返回。
- **中断开关**：`IE` 中 `EA` 是总允许位，`EX0` 开外部中断 0，`IT0` 设触发方式；INT0 对应 `P3.2`，INT1 对应 `P3.3`。
- **服务函数**：`void eint0_isr(void) interrupt 0`，`interrupt 0` 即外部中断 0 的中断号；按键每触发一次，`count++`。
- **组合案例**：主循环不断 `display_num(count)`，INT0 中断里只做计数，数码管上的数字随按键递增。
- **概念区分**：定时器负责计时、计数，中断负责通知 CPU 立即处理事件；定时器溢出可以产生中断，但两者不是一回事。

```c
void eint0_init(void)
{
    EA = 1;   // 总中断
    EX0 = 1;  // 外部中断0
    IT0 = 1;  // 触发方式
}
```

### 5.4 UART 串口

- **定义**：UART（Universal Asynchronous Receiver/Transmitter，串行异步收发器），串行、异步、全双工；用于单片机与单片机、单片机与 PC、单片机与其他主控通信。
- **三根线**：`RXD` 收、`TXD` 发、`GND` 地。双方必须共地，因为电压是相对参考地的差值；接线要交叉，TXD 接对方 RXD。
- **帧格式**：1 位起始位 + 8 位数据位 + 1 位停止位（奇偶校验位省略）；数据按字节从 LSB 到 MSB 逐位发送。
- **异步**：没有时钟线，靠双方约定相同波特率（bps，每秒比特数），常用 2400、4800、9600、115200。
- **初始化**：`SCON = 0x50`（模式 1、允许接收）；`TMOD` 清低 4 位后高 4 位置 `0x20`，让定时器 1 工作在 8 位自动重装；`TH1 = TL1 = 0xFD` 对应 9600；`TR1 = 1` 启动。
- **发送**：写 `SBUF`，等 `TI` 置位，再手动 `TI = 0`；发字符串就是循环调用单字节发送直到 `'\0'`。
- **接收**：开接收、配波特率、开定时器 1、写中断函数、开中断，等待数据到来。

```c
void UartSendByte(unsigned char dat)
{
    SBUF = dat;
    while (TI == 0);
    TI = 0;
}
```

### 5.5 DS18B20 单总线

- **器件**：单总线温度传感器，测量范围 -55℃～+125℃，供电 3.0V～5.5V，可选 9～12 bit 分辨率；12 bit 下一次转换约 750ms。三脚为 GND、DQ（数据，接 `P3.7`）、VCC。
- **复位**：主机拉低总线不少于 480us 后释放，从机在 60～240us 内回一个低电平应答脉冲。
- **写 0 / 写 1**：写 0 是拉低并保持 60～120us；写 1 是先拉低至少 1us，再迅速拉高，让从机采样到高电平。
- **命令**：`0xCC` 跳过 ROM、`0x44` 启动温度转换、`0xBE` 读暂存器（共 9 字节，温度只用前两个）。
- **完整流程**：复位 → `0xCC` → `0x44` → 等待转换（原文流程写等 800ms，覆盖 12 bit 的 750ms）→ 再复位 → `0xCC` → `0xBE` → 读 2 字节，第一字节 LSB（Least Significant Bit，最低有效位）、第二字节 MSB（Most Significant Bit，最高有效位）。
- **换算**：两字节拼成 16 位数值，温度 = 数值 × 0.0625；例如读到 400，则 400 × 0.0625 = 25℃。

## 六、易错点与踩坑

1. **把“输出 1”当成“灯亮”**：开发板 LED 低电平有效，`P2 = 0xFF` 是全灭而不是全亮；换板子前先看原理图。
2. **位选、段选搞反**：位选选“第几位”，段选选“显示什么”；原文的扫描顺序是选位后立刻送段码。
3. **动态扫描太慢**：每一位停留过久，看到的就是逐个跳变的数字，而不是稳定的 1234。
4. **把软件延时当定时器**：`while(t--);` 期间 CPU 什么也做不了，需要并行处理时应改用定时器中断。
5. **只开 `EX0` 忘了 `EA`**：`EA` 是总开关，总开关不开，分开关开了也不响应。
6. **中断号写错**：外部中断 0 对应 `interrupt 0`，编号要与中断源一致。
7. **串口没共地或 TXD 接 TXD**：三根线里地线最容易漏；收发必须交叉，TXD→RXD、RXD→TXD。
8. **波特率不一致或初值照抄**：双方波特率必须一致；原文强调要先设串口模式、确定是否加倍，再按公式算初值，条件变了就不能照抄 `0xFD`。
9. **发完不清 `TI`**：`TI` 由硬件置位、必须软件清零，原文把“清除 TI”列为发送流程的最后一步。
10. **DS18B20 等待不足或时序不准**：12 bit 转换约 750ms，原文流程等 800ms；复位 ≥480us、应答窗口 60～240us、写 0 保持 60～120us 都是 us 级，延时函数不准就容易读错，两次复位后也都要重新发 `0xCC`。

## 七、关键术语

| 术语 | 说明 |
| --- | --- |
| GPIO | 通用输入输出接口（General Purpose Input/Output），STC89C52 有 P0～P3 四组，每组 8 位 |
| 低电平有效 | 端口输出 0 时器件动作；本系列开发板 LED 即 0 亮、1 灭 |
| 位选 | 多位数码管中决定“哪一位”被点亮的控制信号 |
| 段选 | 决定数码管显示什么字符，即 a～g、dp 各段的亮灭组合 |
| 动态扫描 | 逐位快速轮流点亮数码管，扫描足够快时人眼看到的是完整的多位数字 |
| 定时器 | 单片机内部硬件计数器，可定时、计数并在溢出时产生中断 |
| 中断 | CPU 暂停当前程序转去处理事件，处理完返回原处继续执行 |
| 中断服务函数 | 中断触发后执行的函数，Keil C51 用 `interrupt n` 指定中断号 |
| UART | 串行异步收发器（Universal Asynchronous Receiver/Transmitter），串行、异步、全双工 |
| 波特率 | 每秒传输的比特数，单位 bps，通信双方必须一致 |
| 全双工 | 收发各有独立数据线，可以同时发送与接收 |
| 单总线 | 只用一根数据线（另加地线）完成双向通信的协议，DS18B20 采用 |
| 暂存器 | DS18B20 内部 9 字节数据区，温度值放在前两个字节 |
| 分辨率 | DS18B20 可选 9～12 bit；12 bit 下温度换算系数为 0.0625℃ |

## 八、延伸与衔接

- **同一组概念，换一个量级**：05 用 8 位 51 直接写 `P2`、`TH0`、`SCON`；06 系列（i.MX6ULL，Cortex-A7，32 位）仍从点灯、定时器、中断讲起，但每个外设前面都多了一层系统配置。
- **点灯**：51 只需 `P2 = 0xFE`；i.MX6ULL 要先在 IOMUXC 里把焊盘复用为 GPIO、配置电气属性，再设方向和数据，见 [i.MX6ULL—LED点灯](../06-arm-imx6ull/03-i.MX6ULL—LED点灯.md)。
- **中断**：51 只有 INT0、INT1 两个外部中断引脚，靠 `IE`、`TCON` 几位开关；Cortex-A7 由 GIC（Generic Interrupt Controller，通用中断控制器）统一收集中断、排优先级再送 CPU，见 [Cortex-A7中断、GIC与GPIO中断](../06-arm-imx6ull/05-Cortex-A7中断、GIC与GPIO中断.md)。
- **定时器**：51 的 Timer0/Timer1 直接给初值计数；i.MX6ULL 要先配时钟与 PLL（Phase-Locked Loop，锁相环），再用 EPIT/GPT 定时，见 [时钟、PLL、EPIT与GPT定时器](../06-arm-imx6ull/06-时钟、PLL、EPIT与GPT定时器.md)。
- **总线**：05 的 UART 是无时钟的异步串行；06 转向 IIC（Inter-Integrated Circuit）、SPI（Serial Peripheral Interface）这类带时钟的同步总线，05 里“按时序拉低拉高”的手感正好是读时序图的前置训练。
- **学习顺序建议**：先吃透 05 的寄存器级 GPIO 与中断，再进 06；06 的 MMU（Memory Management Unit，内存管理单元）、Cache、虚拟地址在 8 位机上没有对应物，需要单独补。
