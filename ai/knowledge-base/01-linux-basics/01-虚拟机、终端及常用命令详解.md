## 前言

Linux是目前服务器、嵌入式开发、人工智能、云计算等领域使用最广泛的操作系统之一。对于程序员来说，掌握Linux基本命令是必备技能。

---

## 一、Linux虚拟机基本操作

### 1. 全屏模式

为了获得更好的开发体验，可以切换虚拟机全屏。

代码：

```
Ctrl + Alt + Enter
```

---

### 2. 打开终端

Linux的大多数操作都是在终端完成。

代码：

```
Ctrl + Alt + T
```

---

### 3. 新建一个终端

如果需要同时执行多个命令，可以新建终端窗口。

代码：

```
Ctrl + Shift + T
```

---

## 二、Linux终端介绍

打开终端后，一般看到如下内容：

```
linux@linux-virtual-machine:~$
```

各部分含义如下：

| 部分 | 说明 |
| --- | --- |
| linux | 当前登录用户名 |
| linux-virtual-machine | 主机名 |
| ~ | 当前所在目录（家目录） |
| $ | 普通用户 |

如果是root用户，则最后显示

```
#
```

表示超级管理员。

---

## 三、Linux用户

Linux共有两类用户。

### 1、普通用户

特点：

- 权限受到限制
- 可以创建多个
- 用户名不能叫root

例如：

```
linux
tom
jack
```

普通用户家目录：

```
/home/linux
```

---

### 2、超级用户（root）

特点：

- 拥有系统最高权限
- 全系统只有一个
- 用户名固定为root

家目录：

```
/root
```

---

### 3、切换用户

使用：

```
su 用户名
```

例如：

```
su root
```

---

## 四、Linux命令格式

Linux命令统一格式：

```
command [options] arguments
```

例如：

```bash
ls -l
```

其中：

- command：命令
- options：参数
- arguments：对象

---

## 五、man帮助命令

不会使用命令时，可以查看帮助。

```
man ls
```

Linux帮助分为8类：

| 编号 | 内容 |
| --- | --- |
| 1 | 普通命令 |
| 2 | 系统调用 |
| 3 | 库函数 |
| 4 | 设备文件 |
| 5 | 文件格式 |
| 6 | 游戏 |
| 7 | 杂项 |
| 8 | 管理员命令 |

---

## 六、ls命令（查看文件）

最常用命令：

```bash
ls
```

查看详细信息：

```bash
ls -l
```

例如：

```
drwxr-xr-x 3 linux linux 4096 Jul 20 Desktop
```

---

### Linux文件类型

Linux一切皆文件。

常见类型：

| 符号 | 类型 |
| --- | --- |
| - | 普通文件 |
| d | 目录 |
| l | 链接文件 |
| b | 块设备 |
| c | 字符设备 |
| p | 管道 |
| s | Socket |

---

### 文件权限

例如：

```
drwxr-xr-x
```

第一位：

```
d
```

表示目录。

后九位：

```
rwxr-xr-x
```

分为三组：

```
rwx rwx rwx
```

分别表示：

第一组：

> 文件拥有者权限

第二组：

> 同组用户权限

第三组：

> 其他用户权限

其中：

```
r
```

读权限

```
w
```

写权限

```
x
```

执行权限

---

## 七、chmod 修改权限

命令：

```
chmod 权限 文件名
```

例如：

```bash
chmod 664 test.txt
```

数字表示：

| 数字 | 权限 |
| --- | --- |
| 4 | r |
| 2 | w |
| 1 | x |

因此：

```
6 = rw-
7 = rwx
5 = r-x
4 = r--
```

---

## 八、chown 修改所属用户

命令：

```
chown 用户 文件
```

例如：

```
chown root test.txt
```

---

## 九、chgrp 修改所属组

命令：

```
chgrp 组 文件
```

例如：

```
chgrp root test.txt
```

---

## 十、sudo命令

普通用户临时使用管理员权限。

代码：

```bash
sudo apt update
```

代码：

```
sudo 命令
```

---

## 十一、touch 创建文件

创建普通文件：

```
touch hello.txt
```

注意：

Linux不依赖后缀区分文件类型，但建议保留后缀方便识别。

例如：

```
hello.txt
main.c
test.cpp
```

Linux文件名：

✅ 区分大小写

```
hello.txt

Hello.txt
```

属于两个不同文件。

建议不要使用空格。

推荐：

```
my_file.txt
```

---

## 十二、rm 删除文件

删除文件：

```bash
rm hello.txt
```

删除目录：

```bash
rm -rf test
```

⚠ **注意：**

```bash
rm -rf /
```

千万不要执行！

---

## 十三、mkdir 创建目录

创建目录：

```bash
mkdir test
```

一次创建多个目录：

```bash
mkdir test1 test2 test3
```

---

## 十四、rmdir 删除空目录

```
rmdir test
```

只能删除空目录。

非空目录需要：

```bash
rm -rf test
```

---

## 十五、cd切换目录

进入目录：

```bash
cd dirname
```

返回上一层：

```bash
cd ..
```

进入当前目录：

```bash
cd .
```

返回家目录：

```bash
cd ~
```

进入根目录：

```bash
cd /
```

---

## 十六、Linux目录结构

Linux采用树形目录。

```
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── mnt
├── proc
├── root
├── var
```

各目录作用：

| 目录 | 作用 |
| --- | --- |
| /bin | 系统命令 |
| /boot | 启动文件 |
| /dev | 设备文件 |
| /etc | 配置文件 |
| /home | 普通用户目录 |
| /root | 管理员目录 |
| /proc | 进程信息 |
| /var | 日志文件 |

---

## 十七、绝对路径与相对路径

### 绝对路径

从根目录开始。

例如：

```
/home/linux/Desktop
```

任何地方都不会变化。

---

### 相对路径

相对于当前位置。

例如：

```
Desktop
```

不同位置表示不同目录。

---

## 十八、pwd 查看当前目录

查看当前路径：

```
pwd
```

输出：

```
/ home/linux/Desktop
```

## 十九、cp复制文件

复制文件：

```bash
cp file1.txt test/
```

复制目录：

```bash
cp test1 test2 -rf
```

常用：

```
-r
```

递归复制

```
-f
```

强制复制

---

## 二十、mv移动文件

移动文件：

```bash
mv file.txt test/
```

修改文件名：

```bash
mv old.txt new.txt
```

---

## 二十一、综合练习

创建三个目录：

```bash
mkdir test1 test2 test3
```

创建三个文件：

```
touch test1/file1.txt
touch test2/file2.txt
touch test3/file3.txt
```

复制：

```bash
cp test1/file1.txt test2
```

复制目录：

```bash
cp test3 test2 -rf
```

移动目录：

```bash
mv test2 test1
```

修改目录名称：

```bash
mv test1 dirname
```

## 二十二、vi编辑器

打开文件：

```
vi hello.c
```

vi共有三种模式：

① 普通模式

默认进入。

② 插入模式

按

```
i
```

即可输入文字。

③ 命令模式

按

```
ESC
```

后输入：

```
:
```

即可进入。

---

### 常用命令

保存退出：

```
:wq
```

只保存：

```
:w
```

退出：

```
:q
```

强制退出：

```
:q!
```

强制保存退出：

```
:wq!
```

## 二十三、第一个C程序

创建：

```
vi hello.c
```

输入：

```c
#include <stdio.h>

int main()
{
    printf("Hello World!\n");
    return 0;
}
```

保存退出：

```
ESC

:wq
```

## 二十四、gcc编译器

编译：

```bash
gcc hello.c
```

默认生成：

```
a.out
```

指定程序名称：

```bash
gcc hello.c -o hello
```

运行：

```bash
./hello
```

输出：

```
Hello World!
```
