## 一、什么是线程间通信

同一个进程中的多个线程共享进程的地址空间，因此线程之间可以通过**共享变量、共享内存区域**等方式交换数据。

例如：

```
             进程
              │
   ┌──────────┴──────────┐
   ↓                     ↓
线程A                  线程B
   │                     │
   └──────→ 共享变量 ←───┘
```

例如：

```
int num = 100;
```

线程 A 可以修改：

```
num = 200;
```

线程 B 可以读取：

```c
printf("%d\n", num);
```

这就是最简单的线程间通信。

但是：

> **共享数据并不等于线程安全。**

如果多个线程同时操作共享数据，就可能产生**竞态条件**。

因此线程间通信通常需要结合：

- 互斥锁
- 条件变量
- 信号量
- 读写锁
- 消息队列等机制

---

## 二、线程间通信和进程间通信的区别

这是一个非常重要的知识点。

### 进程之间

不同进程拥有独立的地址空间：

```
进程A                    进程B

独立地址空间              独立地址空间
    │                         │
    └────── IPC ─────────────┘
```

因此需要借助：

```
管道
FIFO
消息队列
共享内存
信号
Socket
```

进行通信。

---

### 线程之间

同一个进程中的线程共享地址空间：

```
            进程
             │
  ┌──────────┴──────────┐
  ↓                     ↓
线程A                  线程B
  │                     │
  └──────共享内存───────┘
```

所以线程通信更加方便。

可以直接通过：

```
全局变量
静态变量
堆空间
共享结构体
```

传递数据。

---

## 三、线程间通信的常见方式

Linux pthread 编程中常见的线程同步/通信方式：

```
线程间通信
│
├── 共享变量
│
├── 互斥锁
│
├── 条件变量
│
├── 信号量
│
├── 读写锁
│
└── 其他同步机制
```

其中最重要的是：

> **互斥锁 + 条件变量 + 信号量**

---

## 四、方式一：共享变量

最简单的线程通信方式就是使用共享变量。

例如：

```c
#include <stdio.h>
#include <pthread.h>

int num = 0;

void *thread_fun(void *arg)
{
    num = 100;

    return NULL;
}

int main(void)
{
    pthread_t tid;

    pthread_create(&tid, NULL, thread_fun, NULL);

    pthread_join(tid, NULL);

    printf("num = %d\n", num);

    return 0;
}
```

执行：

```
num = 100
```

这里：

```
int num = 0;
```

属于全局变量。

主线程和子线程都可以访问它。

---

## 五、为什么共享变量还需要同步

假设：

```
int num = 0;
```

创建两个线程：

```
线程A：
num++;

线程B：
num++;
```

我们希望：

```
num = 2
```

但实际上可能出现：

```
线程A                  线程B

读取 num=0
                       读取 num=0
num+1
                       num+1
写入 1
                       写入 1
```

最后：

```
num = 1
```

这就是：

> **竞态条件（Race Condition）**

因此：

```
共享数据
   ↓
可能产生数据竞争
   ↓
需要同步机制
```

## 六、方式二：互斥锁

互斥锁主要用于：

> **保证同一时间只有一个线程访问临界资源。**

核心函数：

```
pthread_mutex_init()
pthread_mutex_lock()
pthread_mutex_unlock()
pthread_mutex_destroy()
```

---

## 七、互斥锁通信示例

```c
#include <stdio.h>
#include <pthread.h>

int num = 0;

pthread_mutex_t mutex;

void *thread_fun(void *arg)
{
    int i = 0;

    for(i = 0; i < 100000; i++)
    {
        pthread_mutex_lock(&mutex);

        num++;

        pthread_mutex_unlock(&mutex);
    }

    return NULL;
}

int main(void)
{
    pthread_t tid1;
    pthread_t tid2;

    pthread_mutex_init(&mutex, NULL);

    pthread_create(&tid1, NULL, thread_fun, NULL);
    pthread_create(&tid2, NULL, thread_fun, NULL);

    pthread_join(tid1, NULL);
    pthread_join(tid2, NULL);

    printf("num = %d\n", num);

    pthread_mutex_destroy(&mutex);

    return 0;
}
```

这里两个线程都访问：

```
num
```

但是：

```
pthread_mutex_lock(&mutex);

num++;

pthread_mutex_unlock(&mutex);
```

保证了同一时间只有一个线程执行：

```
num++;
```

---

## 八、互斥锁解决什么问题

互斥锁主要解决：

```
多个线程
   ↓
同时访问共享资源
   ↓
数据竞争
   ↓
互斥锁
   ↓
保证访问安全
```

但是要注意：

> **互斥锁主要解决“互斥访问”，不负责复杂的线程执行顺序。**

例如：

```
线程A：生产数据
线程B：等待数据
```

这种情况更适合：

```
条件变量
```

或者：

```
信号量
```

---

## 九、方式三：条件变量

条件变量：

```
pthread_cond_t
```

主要用于：

> **让一个线程等待某个条件，让另一个线程在条件满足后唤醒它。**

常见应用：

```
生产者 ——→ 缓冲区 ——→ 消费者
```

---

## 十、生产者消费者模型

这是线程间通信最经典的模型之一。

```
生产者线程
     │
     ↓
  生产数据
     │
     ↓
┌─────────┐
│ 缓冲区   │
└─────────┘
     │
     ↓
  消费数据
     │
     ↓
消费者线程
```

例如：

```
生产者：
生产数字 1
生产数字 2
生产数字 3
```

消费者：

```
读取数字 1
读取数字 2
读取数字 3
```

---

## 十一、为什么需要条件变量

假设消费者先运行：

```
消费者
 ↓
发现缓冲区为空
 ↓
怎么办？
```

不能一直执行：

```
while(buffer_empty)
{
    // 一直循环
}
```

这样会造成：

> **忙等待（Busy Waiting）**

浪费 CPU。

更好的方式：

```
缓冲区为空
 ↓
消费者进入等待
 ↓
生产者生产数据
 ↓
生产者通知消费者
 ↓
消费者被唤醒
 ↓
消费数据
```

这就是条件变量的作用。

---

## 十二、条件变量常用函数

```
pthread_cond_init()
```

初始化。

```
pthread_cond_wait()
```

等待条件。

```
pthread_cond_signal()
```

唤醒一个等待线程。

```
pthread_cond_broadcast()
```

唤醒所有等待线程。

```
pthread_cond_destroy()
```

销毁条件变量。

---

## 十三、pthread_cond_wait()

函数：

```
pthread_cond_wait(&cond, &mutex);
```

它通常和互斥锁一起使用。

例如：

```
pthread_mutex_lock(&mutex);

while(buffer_empty)
{
    pthread_cond_wait(&cond, &mutex);
}

pthread_mutex_unlock(&mutex);
```

这里最重要的一点：

> `pthread_cond_wait()` 会在等待期间释放互斥锁。

这样生产者线程就能够获得这把锁，生产数据。

被唤醒后，等待线程会重新获取互斥锁，然后继续执行。

---

## 十四、pthread_cond_signal()

生产者生产完数据：

```
pthread_cond_signal(&cond);
```

表示：

> 通知一个正在等待这个条件的线程。

例如：

```
生产者
 ↓
生产数据
 ↓
pthread_cond_signal()
 ↓
唤醒消费者
```

---

## 十五、pthread_cond_broadcast()

如果有多个消费者：

```
消费者1
消费者2
消费者3
```

都在等待：

```
pthread_cond_wait()
```

可以使用：

```
pthread_cond_broadcast(&cond);
```

唤醒所有等待线程。

区别：

```
pthread_cond_signal()
        ↓
    唤醒一个

pthread_cond_broadcast()
        ↓
    唤醒全部
```

---

## 十六、生产者消费者简单示例

下面是一个比较典型的条件变量通信程序：

```c
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

int data = 0;
int flag = 0;

pthread_mutex_t mutex;
pthread_cond_t cond;

void *producer(void *arg)
{
    while(1)
    {
        pthread_mutex_lock(&mutex);

        data++;
        flag = 1;

        printf("生产数据：%d\n", data);

        pthread_cond_signal(&cond);

        pthread_mutex_unlock(&mutex);

        sleep(1);
    }

    return NULL;
}

void *consumer(void *arg)
{
    while(1)
    {
        pthread_mutex_lock(&mutex);

        while(flag == 0)
        {
            pthread_cond_wait(&cond, &mutex);
        }

        printf("消费数据：%d\n", data);

        flag = 0;

        pthread_mutex_unlock(&mutex);
    }

    return NULL;
}

int main(void)
{
    pthread_t tid1;
    pthread_t tid2;

    pthread_mutex_init(&mutex, NULL);
    pthread_cond_init(&cond, NULL);

    pthread_create(&tid1, NULL, producer, NULL);
    pthread_create(&tid2, NULL, consumer, NULL);

    pthread_join(tid1, NULL);
    pthread_join(tid2, NULL);

    pthread_cond_destroy(&cond);
    pthread_mutex_destroy(&mutex);

    return 0;
}
```

运行效果类似：

```
生产数据：1
消费数据：1
生产数据：2
消费数据：2
生产数据：3
消费数据：3
```

---

## 十七、为什么这里使用 while 而不是 if

代码：

```
while(flag == 0)
{
    pthread_cond_wait(&cond, &mutex);
}
```

很多初学者容易写成：

```
if(flag == 0)
{
    pthread_cond_wait(&cond, &mutex);
}
```

推荐使用：

```
while
```

原因是：

> **线程被唤醒后，需要再次检查条件是否真的满足。**

线程被唤醒并不代表条件一定满足。

因此经典写法：

```
pthread_mutex_lock(&mutex);

while(条件不满足)
{
    pthread_cond_wait(&cond, &mutex);
}

/* 条件满足，执行操作 */

pthread_mutex_unlock(&mutex);
```

这是条件变量非常重要的编程模式。

## 十八、方式四：信号量

线程之间还可以使用：

> **信号量（Semaphore）**

Linux 中常用：

```
#include <semaphore.h>
```

数据类型：

```
sem_t
```

---

## 十九、信号量的核心思想

信号量可以理解为：

> **一个用于控制资源数量和线程执行顺序的计数器。**

例如：

```
sem = 3
```

表示当前有：

```
3个资源
```

线程获取资源：

```
sem_wait()
```

资源数量减少：

```
3 → 2
```

线程释放资源：

```
sem_post()
```

资源数量增加：

```
2 → 3
```

---

## 二十、信号量常用函数

初始化：

```
sem_init()
```

等待/申请资源：

```
sem_wait()
```

释放资源：

```
sem_post()
```

销毁：

```
sem_destroy()
```

---

## 二十一、sem_init()

函数：

```
int sem_init(
    sem_t *sem,
    int pshared,
    unsigned int value
);
```

例如：

```
sem_t sem;

sem_init(&sem, 0, 1);
```

这里：

```
&sem
 ↓
信号量

0
 ↓
线程间使用

1
 ↓
初始值
```

---

## 二十二、sem_wait()

```
sem_wait(&sem);
```

可以理解为：

> 申请一个资源。

如果信号量大于 0：

```
sem = 1
 ↓
wait
 ↓
sem = 0
 ↓
继续执行
```

如果：

```
sem = 0
```

那么线程就会：

```
进入阻塞等待
```

直到其他线程执行：

```
sem_post()
```

---

## 二十三、sem_post()

```
sem_post(&sem);
```

表示：

> 释放一个资源。

例如：

```
sem = 0
 ↓
sem_post()
 ↓
sem = 1
```

等待的线程就可能被唤醒。

---

## 二十四、信号量实现线程同步

例如：

```
线程A
 ↓
执行任务A
 ↓
通知线程B
```

线程B：

```
等待通知
 ↓
执行任务B
```

可以使用两个信号量。

```
sem_t sem_A;
sem_t sem_B;
```

初始化：

```
sem_init(&sem_A, 0, 1);
sem_init(&sem_B, 0, 0);
```

---

## 二十五、A、B、C三个线程按顺序执行

这是非常经典的线程同步练习。

要求：

```
A
B
C
A
B
C
...
```

可以使用三个信号量：

```
sem_t sem_A;
sem_t sem_B;
sem_t sem_C;
```

初始化：

```
sem_init(&sem_A, 0, 1);
sem_init(&sem_B, 0, 0);
sem_init(&sem_C, 0, 0);
```

---

## 二十六、线程A

```c
void *thread_A(void *arg)
{
    while(1)
    {
        sem_wait(&sem_A);

        printf("A\n");

        sem_post(&sem_B);
    }

    return NULL;
}
```

执行过程：

```
sem_A = 1
   ↓
A线程获得信号量
   ↓
打印 A
   ↓
sem_post(&sem_B)
   ↓
通知B线程
```

---

## 二十七、线程B

```c
void *thread_B(void *arg)

        printf("B\n");

        sem_post(&sem_C);
    }

    return NULL;
}
```

过程：

```
等待 sem_B
   ↓
收到A的通知
   ↓
打印B
   ↓
通知C
```

## 二十八、线程C

```c
void *thread_C(void *arg)

    while(1)

```

过程：

```
等待 sem_C
   ↓
收到B的通知
   ↓

   ↓

```

最终形成：

```

 ↓
C

A
 ↓
B
 ↓

 ↓
...
```

整个过程可以画成：

   sem_A
     │

     │
 printf("A")
     │

```

## 三十、互斥锁和信号量的区别

这是考试和实际编程中都非常重要的内容。

| 对比 | 互斥锁 | 信号量 |
| --- | --- | --- |
| 类型 | Mutex | Semaphore |
| 核心作用 | 互斥访问 | 同步/资源计数 |
| 数量 | 通常表示一把锁 | 可以是多个资源 |
| 常见函数 | `lock/unlock` | `wait/post` |
| 典型用途 | 保护临界区 | 线程同步、资源控制 |

简单理解：

```
互斥锁：
    这个资源一次只能一个人用

信号量：
    现在还有几个资源可以用
```

---

## 三十一、互斥锁和信号量的典型使用场景

#### 互斥锁

例如：

```
num++;
```

需要保证：

```
同一时刻只能一个线程修改num
```

使用：

```
pthread_mutex_lock()
pthread_mutex_unlock()
```

---

#### 信号量

例如：

```
线程A执行完
 ↓
线程B才能执行
```

使用：

```
sem_post()
sem_wait()
```

## 三十二、条件变量和信号量的区别

两者都可以实现线程同步，但机制不同。

#### 条件变量

通常需要：

```
互斥锁 + 条件变量
```

例如：

```
缓冲区为空
 ↓
消费者等待
 ↓
生产者生产
 ↓
signal
 ↓
消费者继续
```

---

#### 信号量

信号量本身就带有计数功能。

例如：

```
sem = 0

消费者：
sem_wait()
 ↓
等待

生产者：
sem_post()
 ↓
通知
```

## 三十三、方式五：读写锁

线程间通信和同步中还有：

```
读写锁
```

类型：

```
pthread_rwlock_t
```

适合：

> **读操作很多、写操作较少的共享资源。**

基本规则：

```
多个读线程
    ↓
可以同时读取

写线程
    ↓
独占访问
```

例如：

```
   共享数据
      │
 ┌────┼────┐
 ↓    ↓    ↓
读1   读2   读3
```

三个线程可以同时读取。

但是写的时候：

```
   写线程
      ↓
独占共享资源
```

---

读锁：

```
pthread_rwlock_rdlock()
```

写锁：

```
pthread_rwlock_wrlock()
```

```

    +

```

例如：

```

    ↓

    ↓

## 三十七、生产者消费者模型完整思路

这是本章最值得掌握的模型。

```
   生产者
      │
      ↓
┌──────────┐
│ 共享缓冲区 │
└──────────┘
      │
      ↓
   消费者
```

生产者：

```
加锁
 ↓
判断缓冲区
 ↓
生产数据
 ↓
通知消费者
 ↓
解锁
```

消费者：

```
加锁
 ↓
判断缓冲区
 ↓
没有数据 → wait
 ↓
有数据
 ↓
消费数据
 ↓
通知生产者
 ↓
解锁
```

所以生产者消费者问题综合了：

```
共享变量
+
互斥锁
+
条件变量
```

## 三十八、线程通信中的几个重要概念

#### 1. 共享资源

多个线程共同访问的数据。

例如：

```
int num;
```

---

#### 2. 临界区

访问共享资源的代码。

例如：

```
num++;
```

---

#### 3. 竞态条件

多个线程并发访问共享数据，最终结果依赖执行时序。

---

#### 4. 互斥

同一时间只能允许一个线程访问临界资源。

---

#### 5. 同步

多个线程按照一定的条件和顺序协同工作。

---

#### 6. 死锁

多个线程相互等待对方持有的资源，导致所有线程无法继续执行。

## 三十九、本章函数总结

| 函数 | 作用 |

| `pthread_mutex_init()` | 初始化互斥锁 |

| `pthread_mutex_destroy()` | 销毁互斥锁 |
| `pthread_cond_init()` | 初始化条件变量 |
| `pthread_cond_wait()` | 等待条件 |
| `pthread_cond_signal()` | 唤醒一个线程 |
| `pthread_cond_broadcast()` | 唤醒所有线程 |
| `pthread_cond_destroy()` | 销毁条件变量 |
| `sem_init()` | 初始化信号量 |
| `sem_wait()` | 等待/申请信号量 |
| `sem_post()` | 释放/增加信号量 |
| `sem_destroy()` | 销毁信号量 |
| `pthread_rwlock_init()` | 初始化读写锁 |
| `pthread_rwlock_rdlock()` | 获取读锁 |
| `pthread_rwlock_wrlock()` | 获取写锁 |
| `pthread_rwlock_unlock()` | 解锁 |
| `pthread_rwlock_destroy()` | 销毁读写锁 |
