## 一、什么是 IO

IO 是：

```
I：Input      输入
O：Output     输出
```

例如：

```
键盘 ─────→ 程序
       输入

程序 ─────→ 屏幕
       输出

文件 ─────→ 程序
       输入

程序 ─────→ 文件
       输出
```

在 Linux 软件编程中，IO 主要包括：

```
文件 IO
标准 IO
设备 IO
网络 IO
```

本阶段主要学习**文件 IO 和标准 IO**。

---

## 二、Linux 中的文件

文件可以理解为：

> **存放在磁盘空间中的一段数据的集合。**

课程资料中对文件的定义也是“存放在磁盘空间中的一段数据的集合”。

Linux 中一个非常重要的思想是：

> **Linux 系统中一切皆是文件。**

Linux 内核的重要功能之一就是文件系统管理。

因此，在 Linux 中不仅普通文本文件可以进行 IO，一些设备、管道等也可以通过文件相关机制进行操作。

---

## 三、文件操作的三个步骤

对文件进行操作，一般需要经过三个步骤：

```
  文件
   ↓
① 打开
   ↓
② 读写
   ↓
③ 关闭
```

也就是：

```
open
 ↓
read / write
 ↓
close
```

对于 C 标准 IO，则对应：

```
fopen
 ↓
fgetc / fputc
fgets / fputs
fprintf / fscanf
fread / fwrite
 ↓
fclose
```

课程笔记中也按照“打开文件 → 读写文件 → 关闭文件”的顺序整理了文件 IO。

---

## 四、ASCII 文件和二进制文件

文件从数据存储形式上可以分为：

```
ASCII 文件
二进制文件
```

### 1. ASCII 文件

ASCII 文件中的数据主要以字符形式保存。

例如：

```
hello world
123456
Linux
```

常见的文本文件：

```
.txt
.c
.h
.sh
```

例如 C 源代码：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello Linux\n");

    return 0;
}
```

本质上就是一个文本文件。

---

### 2. 二进制文件

二进制文件中的数据不一定能够直接以可显示字符的形式呈现在终端中。

常见的二进制数据：

```
图片
音频
视频
压缩包
可执行文件
```

例如：

```
a.out
.jpg
.mp3
.mp4
.zip
```

需要注意：

> **ASCII 文件本质上也是二进制文件的一种特殊形式。**

课程资料中也明确指出，ASCII 文件属于特殊的二进制文件。

## 五、C 标准 IO

C 语言中提供了一套标准 IO 接口，主要包含：

```
fopen()
fclose()

fputc()
fgetc()

fputs()
fgets()

fprintf()
fscanf()

fwrite()
fread()
```

这些函数主要定义在：

```
#include <stdio.h>
```

中。

标准 IO 使用：

```
FILE *
```

来表示一个**文件流**。

例如：

```
FILE *fp = NULL;
```

## 六、fopen() 打开文件

函数原型：

```
FILE *fopen(const char *pathname, const char *mode);
```

其中：

```
pathname
    ↓
文件路径

mode
    ↓
打开方式
```

例如：

```
FILE *fp = fopen("file.txt", "r");
```

表示：

> 以只读方式打开 `file.txt`。

课程资料中给出了 `fopen()` 的基本接口及其返回值规则：成功返回文件流指针，失败返回 `NULL`。

---

## 七、fopen() 常见打开方式

### 1. `r`

只读。

```
FILE *fp = fopen("file.txt", "r");
```

特点：

```
文件存在 → 打开
文件不存在 → 失败
```

---

### 2. `r+`

读写。

```
FILE *fp = fopen("file.txt", "r+");
```

特点：

```
文件存在 → 读写
文件不存在 → 失败
```

---

### 3. `w`

只写。

```
FILE *fp = fopen("file.txt", "w");
```

特点：

```
文件不存在 → 创建
文件存在   → 清空
```

---

### 4. `w+`

读写。

```
FILE *fp = fopen("file.txt", "w+");
```

特点：

```
文件不存在 → 创建
文件存在   → 清空
```

---

### 5. `a`

追加写。

```
FILE *fp = fopen("file.txt", "a");
```

特点：

```
文件不存在 → 创建
文件存在   → 在末尾追加
```

---

### 6. `a+`

追加读写：

```
FILE *fp = fopen("file.txt", "a+");
```

课程笔记中对 `r`、`r+`、`w`、`w+`、`a`、`a+` 的区别进行了完整整理。

---

## 八、fopen() 返回值判断

打开文件后一定要判断是否成功：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;

    fp = fopen("file.txt", "r");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    printf("open success\n");

    fclose(fp);

    return 0;
}
```

核心：

```
if(fp == NULL)
```

说明：

```
fp == NULL
    ↓
打开失败

fp != NULL
    ↓
打开成功
```

---

## 九、fclose() 关闭文件

打开文件后，使用完一定要关闭。

```
fclose(fp);
```

函数原型：

```
int fclose(FILE *stream);
```

返回值：

```
0
    ↓
成功

EOF
    ↓
失败
```

课程资料中也明确记录了 `fclose()` 的返回值。

因此基本结构：

```
FILE *fp = NULL;

fp = fopen("file.txt", "r");

if(fp == NULL)
{
    perror("fopen");
    return -1;
}

/* 文件操作 */

fclose(fp);
```

---

## 十、fputc() —— 写一个字符

函数：

```
int fputc(int c, FILE *stream);
```

作用：

> 向指定文件流中写入一个字符。

例如：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;

    fp = fopen("a.txt", "w");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    fputc('H', fp);
    fputc('e', fp);
    fputc('l', fp);
    fputc('l', fp);
    fputc('o', fp);

    fclose(fp);

    return 0;
}
```

执行后：

```
a.txt
```

中会出现：

```
Hello
```

课程资料中指出，`fputc()` 成功时返回写入字符对应的 ASCII 码，失败时返回 `EOF`。

---

## 十一、fgetc() —— 读取一个字符

函数：

```
int fgetc(FILE *stream);
```

作用：

> 从指定文件流中读取一个字符。

例如：

```
char ch;

ch = fgetc(fp);
```

但是这里有一个非常重要的细节：

#### 为什么不用 `char` 接收？

推荐：

```
int ch;
```

而不是：

```
char ch;
```

因为 `fgetc()` 不仅需要返回字符，还需要返回：

```
EOF
```

所以返回值类型是：

```
int
```

例如：

```c
int ch;

while((ch = fgetc(fp)) != EOF)
{
    putchar(ch);
}
```

这种写法非常重要。

课程资料中也明确说明：

```
fgetc()
成功 → 返回字符 ASCII 码
失败 → EOF
文件结束 → EOF
```

---

## 十二、利用 fgetc() 统计文件行数

例如统计 `file.txt` 有多少行：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;
    int ch = 0;
    int cnt = 0;

    fp = fopen("file.txt", "r");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    while((ch = fgetc(fp)) != EOF)
    {
        if(ch == '\n')
        {
            cnt++;
        }
    }

    printf("line = %d\n", cnt);

    fclose(fp);

    return 0;
}
```

这里需要注意：

```
ch == '\n'
```

表示遇到换行符。

而：

```
ch == EOF
```

表示读取结束。

---

## 十三、fputs() —— 写字符串

函数：

```
int fputs(const char *s, FILE *stream);
```

例如：

```
fputs("Hello Linux\n", fp);
```

会把字符串写入文件。

例如：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;

    fp = fopen("a.txt", "w");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    fputs("Hello Linux\n", fp);
    fputs("Linux IO\n", fp);

    fclose(fp);

    return 0;
}
```

课程资料中指出，`fputs()` 不会额外添加 `\n`。

所以：

```
fputs("hello", fp);
```

不会自动换行。

如果需要换行：

```
fputs("hello\n", fp);
```

---

## 十四、fgets() —— 读取一行字符串

函数：

```
char *fgets(char *s, int size, FILE *stream);
```

例如：

```c
char buf[128] = {0};

fgets(buf, sizeof(buf), fp);
```

作用：

> 从文件流中读取一行字符串。

例如：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;
    char buf[128] = {0};

    fp = fopen("file.txt", "r");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    while(fgets(buf, sizeof(buf), fp) != NULL)
    {
        printf("%s", buf);
    }

    fclose(fp);

    return 0;
}
```

课程资料指出，`fgets()` 从流中读取一行字符串，并且读取失败或到达文件末尾时返回 `NULL`。

---

## 十五、fgets() 和 gets() 的区别

这两个函数非常容易混淆。

#### `gets()`

```
gets(buf);
```

存在缓冲区溢出风险，现代 C 编程中**不应该使用**。

#### `fgets()`

```
fgets(buf, sizeof(buf), stdin);
```

可以指定最大读取长度，更安全。

另外：

```
fgets()
```

从终端读取时，如果输入中包含换行符，通常会将 `\n` 一起读入字符串。

所以：

```
char buf[100];

fgets(buf, sizeof(buf), stdin);
```

输入：

```
hello
```

实际可能得到：

```
'h' 'e' 'l' 'l' 'o' '\n' '\0'
```

课程笔记也特别记录了 `gets()` 和 `fgets()` 对换行符处理的区别。

---

## 十六、fprintf() —— 格式化写文件

`fprintf()` 和 `printf()` 很像。

区别：

```
printf()
```

默认向标准输出写。

而：

```
fprintf()
```

可以指定输出流。

例如：

```c
fprintf(fp, "name = %s\n", "linux");
fprintf(fp, "age = %d\n", 20);
```

最终写入：

```
name = linux
age = 20
```

因此可以记：

```
printf
    ↓
标准输出

fprintf
    ↓
指定文件流
```

---

## 十七、fscanf() —— 从文件格式化读取

类似：

```
scanf()
```

`fscanf()` 可以从指定流中读取数据。

例如文件：

```
100 200
```

代码：

```
int a = 0;
int b = 0;

fscanf(fp, "%d %d", &a, &b);
```

读取后：

```
a = 100
b = 200
```

所以：

```
scanf()
    ↓
标准输入

fscanf()
    ↓
指定文件流
```

---

## 十八、fread() 和 fwrite()

对于二进制文件，常用：

```
fread()
fwrite()
```

例如：

```
fwrite(&data, sizeof(data), 1, fp);
```

读取：

```
fread(&data, sizeof(data), 1, fp);
```

它们适合处理：

```
结构体
图片
音视频数据
二进制数据
```

课程资料将 `fwrite/fread` 与字符、字符串、格式化 IO 一起列为标准 IO 的文件读写接口。

## 十九、标准 IO 的三个默认流

程序启动后，系统会默认打开三个标准流：

```
stdin
stdout
stderr
```

分别是：

| 流 | 含义 | 默认设备 |
| --- | --- | --- |
| `stdin` | 标准输入 | 键盘 |
| `stdout` | 标准输出 | 屏幕 |
| `stderr` | 标准错误 | 屏幕 |

课程资料中也明确列出了这三个默认打开的流。

例如：

```c
printf("Hello\n");
```

本质上是向：

```
stdout
```

输出。

而：

```
scanf("%d", &num);
```

则是从：

```
stdin
```

读取。

## 二十、标准 IO 的缓存

标准 IO 一个非常重要的特点：

> **标准 IO 是有缓存的 IO。**

用户调用标准 IO 函数后，数据通常会先进入用户空间的缓冲区，在满足刷新条件后再传递给内核。

主要有三种：

```
全缓存
行缓存
不缓存
```

---

### 1. 全缓存

缓存区满时刷新。

文件流通常采用全缓存。

课程资料中给出的典型大小是：

```
4KB = 4096 Bytes
```

刷新条件包括：

```
① 缓冲区满
② fflush()
③ fclose()
④ 程序结束
```

---

### 2. 行缓存

遇到：

```
'\n'
```

时刷新。

终端相关的流通常采用行缓存。

典型大小：

```
1KB = 1024 Bytes
```

例如：

```c
printf("hello\n");
```

遇到 `\n` 后通常会触发刷新。

---

### 3. 不缓存

数据产生后立即刷新。

例如：

```
stderr
```

通常采用不缓存方式。

适用于：

```
错误处理
实时性要求高
人机交互
```

---

## 二十一、标准 IO 与系统 IO

Linux 编程中需要区分：

#### 标准 IO

```
fopen()
fclose()
fgetc()
fputc()
fgets()
fputs()
fprintf()
fscanf()
fread()
fwrite()
```

使用：

```
FILE *
```

---

#### 系统 IO

后续 Linux 系统编程中会学习：

```
open()
close()
read()
write()
lseek()
```

使用：

```
int fd;
```

可以简单理解：

```
C 标准 IO
    ↓
FILE *
    ↓
带缓存

Linux 系统 IO
    ↓
文件描述符 fd
    ↓
系统调用
```

另外，Linux 中的库函数通常是对系统调用的封装，可以提供更方便、更通用的接口；系统调用则是 Linux 内核提供的接口。

## 二十二、标准 IO 学习流程

以后写文件程序，可以按照这个思路：

```
      开始
        ↓
    定义 FILE *
        ↓
    fopen()
        ↓
  判断是否 NULL
    ↙       ↘
  是         否
  ↓          ↓
报错       文件操作
             ↓
        读 / 写
             ↓
          fclose
             ↓
            结束
```

代码模板：

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;

    /* 1. 打开 */
    fp = fopen("file.txt", "r");

    if(fp == NULL)
    {
        perror("fopen");
        return -1;
    }

    /* 2. 读写文件 */

    /* 3. 关闭 */
    fclose(fp);

    return 0;
}
```

### 二十四、学习 IO 时最容易出错的几个地方

#### 1. `fopen()` 后忘记判断

错误：

```
FILE *fp = fopen("a.txt", "r");

fgetc(fp);
```

正确：

```
FILE *fp = fopen("a.txt", "r");

if(fp == NULL)
{
    perror("fopen");
    return -1;
}
```

---

#### 2. `fgetc()` 不要用 `char` 判断 EOF

不推荐：

```
char ch;

while((ch = fgetc(fp)) != EOF)
```

推荐：

```c
int ch;

while((ch = fgetc(fp)) != EOF)
{
    putchar(ch);
}
```

因为 `fgetc()` 的返回值类型是 `int`，需要能够表示所有字符值以及 `EOF`。

---

#### 3. `fputs()` 不会自动换行

```
fputs("hello", fp);
```

不会换行。

需要：

```
fputs("hello\n", fp);
```

---

#### 4. `fgets()` 要注意数组大小

推荐：

```
char buf[100];

fgets(buf, sizeof(buf), fp);
```

而不是随意指定一个超过数组实际容量的长度。

---

#### 5. 文件打开后要关闭

```
fclose(fp);
```

这是良好的资源管理习惯。
