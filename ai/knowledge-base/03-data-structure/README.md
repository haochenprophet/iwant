# 03 · 数据结构学习笔记

> 原文出处：CSDN「斑马819」《数据结构学习笔记》系列，共 5 篇，发布于 2026-08-13 至 2026-08-17。

## 一、系列定位

本系列是一组以 C 语言手写实现为主线的入门笔记，从顺序表（Sequential List，SeqList）起步，依次走到链表、队列与二叉树。开篇先把「程序 = 数据结构 + 算法」摆出来，按逻辑关系区分线性、树形、图形结构，按存储方式区分顺序、链式、散列与索引存储，随后每一篇都落到可编译的结构体定义和增删查改函数上。

它的重点不在刷题，而在建立两件事的直觉：数据元素之间如何用指针或下标关联，堆区内存如何申请、使用与释放。五篇代码统一使用 `struct`、`typedef`、`malloc` 与 `free`，风格连续，适合作为后续阅读内核数据结构与嵌入式代码的过渡。

## 二、前置知识与环境

- **语言基础**：C 语言的指针、结构体、`typedef`、数组、函数参数传递，尤其是修改头指针时用到的二级指针。
- **内存管理**：分得清堆区与栈区，会用 `malloc`、`free`、`sizeof`；知道申请后必须判空，释放后应把指针置 `NULL`。
- **输入输出**：`printf`、`scanf`；第 5 篇用 `scanf(" %c", &ch)` 逐字符读取建树输入。
- **编译环境**：正文只依赖 `stdio.h`、`stdlib.h`、`stdbool.h`，代码为单文件风格（第 2 篇明确给出 `main.c`），用常见 C 编译器即可复现；原文未绑定具体 IDE 或操作系统。

## 三、知识脉络

1. **顺序表**把线性表放进一段连续内存：按下标随机访问是 O(1)，代价是插入、删除要成批搬移元素，且容量在创建时指定。
2. **单向链表**改用指针串联离散结点，头插使数据逆序、尾插使数据保序；带头结点后，空表与非空表的边界处理被统一。
3. **双向链表与循环链表**在同一结点上增加反向指针，或让尾结点接回头结点，解决单向不可回退、走到 `NULL` 就停的局限。
4. **队列**把线性表的操作限制为「队尾进、队头出」：顺序实现暴露出假溢出，循环队列用取模回到起点，链式实现则直接复用结点操作。
5. **二叉树**从一对一的线性关系跨到一对多的树形关系：递归遍历对应系统函数调用栈，层序遍历对应第 4 篇的链式队列，非递归遍历则是自己建栈模拟系统栈。

## 五、核心要点

### 5.1 顺序表

- **结构定义**：用一组地址连续的存储单元依次存放线性表（Linear List）元素，属于顺序存储结构。三个成员分别记录数据区、总容量与当前长度。
```c
typedef struct seqlist {
    DataType *pData;   // 堆区数组首地址
    int tlen;          // 总容量 Total Length
    int clen;          // 当前长度 Current Length
} SeqList_t;
```
- **核心操作**：创建（分别申请结构体与数组两块堆内存）、判空判满、指定位置插入、指定位置删除、按值查找、打印、销毁。
- **复杂度**：按下标随机访问 O(1)；按值查找 O(n)；头部或中间插入、删除 O(n)；尾部插入、删除 O(1)。空间连续、无需指针域，原文评价为空间利用率高。
- **实现要点**：插入时下标从 `clen` 起倒序搬移，把 `pos` 及之后的元素后移一位；删除时从 `pos` 起正序前移覆盖；销毁先 `free(pData)`，再释放结构体，并把外部指针置 `NULL`。

### 5.2 单向链表

- **结构定义**：逻辑上线性、物理上非连续的链式表，每个结点含数据域与指向后继的指针域；采用带头结点（Header Node）的写法，头结点不存有效数据。
```c
typedef struct Node {
    ElemType data;
    struct Node *next;
} LinkNode, *LinkedList;
```
- **核心操作**：初始化头结点、头插、尾插、遍历打印、按值删除、销毁整表。
- **复杂度**：原文未给复杂度表；对照表只说明按下标随机访问需从头顺序遍历，插入与删除只需修改指针指向，但每个结点要多付一个指针域的存储开销。
- **实现要点**：头插的 `new_node->next = head->next` 必须先于 `head->next = new_node`；尾插先走到 `p->next == NULL` 的尾结点再接新结点；按值删除先停在前驱，跨接后 `free`；销毁时用临时指针暂存后继再释放当前结点。

### 5.3 双向链表与循环链表

- **结构定义**：双向链表（Doubly Linked List）结点在 `data` 之外同时保存 `pPrev` 与 `pNext`；循环链表（Circular Linked List）不改变结点结构，只把最后一个结点的 `pNext` 从 `NULL` 改为指向第一个结点。
```c
typedef struct Node {
    int data;
    struct Node *pPrev;
    struct Node *pNext;
} Node_t;
```
- **核心操作**：创建结点、头插、尾插、删除指定结点、正向与反向遍历；循环链表用 `do { ... } while (pCurrent != pHead);` 遍历；循环双向链表另有 `head->pPrev = tail` 与 `tail->pNext = head`。
- **复杂度**：原文未给复杂度；只从空间与操作便利性比较，双向链表每个结点多一个指针、空间开销更大，换来反向遍历和更省事的删除；循环链表没有 `NULL` 结束标志，适合约瑟夫环、循环队列、任务调度一类需要循环访问的场景。
- **实现要点**：插入和删除都要同时维护前驱的 `pNext` 与后继的 `pPrev`；删除头结点要单独更新 `*ppHead`，并把新头结点的 `pPrev` 置 `NULL`；循环链表删除后必须重新接上前后结点，再 `free` 被删结点。

### 5.4 队列

- **结构定义**：队列（Queue）是先进先出（FIFO，First In First Out）的线性结构。顺序队列用定长数组加两个下标，链式队列（Linked Queue）用结点加队头、队尾指针。
```c
typedef struct {
    DataType Data[10];
    int Front;
    int Rear;
} SeqQueue_t;
```
- **核心操作**：`CreateQueue`、`IsEmptyQueue`、`EnterQueue`（入队）、`QuitQueue`（出队）、`DestroyQueue`；链式版本入队要建结点，出队要释放结点。
- **复杂度**：原文未列复杂度表；只说明顺序队列入队、出队改下标即可，链式队列入队需先找到最后一个结点，出队固定删除队头结点。
- **实现要点**：普通顺序队列出队只移动 `Front`，数组前部空位无法复用，形成假溢出（False Overflow）；循环队列（Circular Queue）用 `(index + 1) % MAXSIZE` 让下标回到开头；队空为 `Front == Rear`，入队前用 `(Rear + 1) % 10 == Front` 判满；链式队列用不存数据的头结点，入队在尾部接结点，出队删除头结点后的第一个结点并 `free`。

### 5.5 二叉树

- **结构定义**：二叉树（Binary Tree）每个结点最多有左、右两个子结点，用二叉链表存储。
```c
typedef struct btreenode {
    int No;
    char Data;
    struct btreenode *pLeftChild;
    struct btreenode *pRightChild;
} BTreeNode_t;
```
- **核心操作**：按编号递归创建完全二叉树（Complete Binary Tree），左孩子编号 `2 * StartNo`、右孩子 `2 * StartNo + 1`；按 `#` 表示空结点的先序输入建树；前序遍历（Preorder Traversal）、中序遍历（Inorder Traversal）、后序遍历（Postorder Traversal）递归遍历；借链式队列做层序遍历（Level Order Traversal）；递归求高度；后序销毁；借链式栈做三种非递归遍历。
- **复杂度**：原文没有给出复杂度表，重点在遍历与递归、栈、队列的对应关系：递归依赖系统函数调用栈（Call Stack），非递归则自建链式栈模拟；层序遍历依赖队列的先进先出。
- **实现要点**：高度为 `max(左子树高度, 右子树高度) + 1`，空树高度为 0；销毁必须后序，先释放左右子树再 `free` 根结点；非递归前序压栈时先右后左，中序沿左孩子一路压栈再出栈转向右子树，后序用两个栈把「根右左」反转为「左右根」；队列与栈的数据域改为 `void *`，取出时再强制转换为 `BTreeNode_t *`。

## 六、易错点与踩坑

1. **指针修改顺序颠倒**：头插若先执行 `head->next = new_node`，原链表入口就被覆盖，后续结点全部丢失；必须遵循「先连后断」。
2. **释放后不置空**：`free` 只归还堆内存，指针仍保存旧地址；删除结点、销毁整表后都应把指针置 `NULL`。
3. **缺少空表判断**：凡要访问 `p->next` 的循环，都要先确认当前结点非空，否则可能访问 `NULL` 地址触发段错误（Segmentation fault）。
4. **双向链表只改一个方向**：只写 `pCurrent->pNext = pNewNode` 而漏掉 `pNewNode->pPrev = pCurrent`，正向能走、反向已断。
5. **循环链表用 `NULL` 判终止**：循环链表里没有 `NULL`，`while (pCurrent != NULL)` 会一直转；应改为 `pCurrent != pHead` 或 `do-while`。
6. **循环链表删除后不重连**：只 `free` 不接回前后结点，链表会指向已释放内存，后续访问可能段错误。
7. **顺序队列的假溢出**：出队只移动 `Front`，前面的空位再也用不上，元素未真正占满却入队失败。
8. **链式队列出队忘记释放**：出队只是摘下结点，仍须 `free(pFreeNode)`，否则每出队一次就泄漏一块堆内存。
9. **`sizeof` 用错对象**：`malloc(sizeof(pTmpNode))` 申请的是指针大小，不是结构体大小，应写 `malloc(sizeof(Node_t))`。
10. **`No` 与 `Data` 混用**：建树时写入 `Data`，遍历却打印 `No`，输出与预期不符；字段必须前后一致。

## 七、关键术语

| 术语 | 说明 |
| --- | --- |
| 线性表（Linear List） | 数据元素之间呈一对一关系的逻辑结构 |
| 顺序表（Sequential List，SeqList） | 用地址连续的存储单元依次存放元素的线性表 |
| 链表（Linked List） | 结点通过指针相连、物理存储可以不连续的线性表 |
| 头结点（Header Node） | 放在第一个有效结点之前、不存有效数据的辅助结点，用于统一插入删除的边界处理 |
| 双向链表（Doubly Linked List） | 每个结点同时保存前驱指针与后继指针的链表 |
| 循环链表（Circular Linked List） | 最后一个结点指回第一个结点、没有 `NULL` 结尾的链表 |
| 队列（Queue） | 只允许在队尾入队、在队头出队的先进先出线性结构 |
| 先进先出（FIFO，First In First Out） | 最先进入的数据最先离开的存取规则 |
| 假溢出（False Overflow） | 顺序队列中 `Front` 前移留下空位、`Rear` 却到达数组末端而无法继续入队的现象 |
| 循环队列（Circular Queue） | 用取模运算让下标回到数组开头、复用已出队空间的顺序队列 |
| 链式队列（Linked Queue） | 用链表结点实现的队列，队尾入队、队头出队 |
| 二叉树（Binary Tree） | 每个结点最多有左、右两个子结点的树形结构 |
| 完全二叉树（Complete Binary Tree） | 按层序编号后，左孩子编号为 `2n`、右孩子编号为 `2n+1` 的二叉树 |
| 前序遍历（Preorder Traversal） | 按根、左、右次序访问结点的深度优先遍历 |
| 中序遍历（Inorder Traversal） | 按左、根、右次序访问结点的深度优先遍历 |
| 后序遍历（Postorder Traversal） | 按左、右、根次序访问结点的深度优先遍历 |
| 层序遍历（Level Order Traversal） | 自上而下、自左而右逐层访问，又称广度优先遍历 |
| 函数调用栈（Call Stack） | 递归调用时由系统维护、保存调用信息与局部变量的栈 |

## 八、延伸与衔接

**与 `04-linux-sysprog` 的内核链表、队列**：内核里的双向链表把前驱、后继指针直接嵌进业务结构体，插入删除时同样要成对维护两个方向，只是把第 3 篇的 `pPrev`、`pNext` 换成了通用结点与宏；内核的环形缓冲则延续第 4 篇循环队列的取模思路，队空、队满的判断条件依旧是阅读代码的第一道门槛。

**与 `05-mcu-8051`**：在 8051 这类资源受限的单片机场景里，顺序表与静态数组往往比动态链表更实用；串口收发常见的环形缓冲区，也可以直接套用第 4 篇循环队列的取模写法。中断与主循环共享同一组队头、队尾下标时，笔记里 `Front` 与 `Rear` 的更新顺序、判空判满条件会直接决定数据会不会被覆盖。

**与 `06-arm-imx6ull`**：在 ARM 平台写驱动或应用时，设备与缓冲区常用链表组织，生产者消费者常用队列衔接；第 5 篇「递归靠系统栈、非递归自建栈」的对照，也有助于理解函数调用栈、中断现场保存这类底层机制。把本系列的指针操作练熟，再读这些场景的代码，阻力会小很多。
