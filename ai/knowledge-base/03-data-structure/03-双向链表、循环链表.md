### 一、双向链表

#### 1. 什么是双向链表

单链表的节点只有一个指针：

```c
typedef struct Node
{
    int data;
    struct Node *pNext;
} Node_t;
```

只能：

```
前一个节点 → 当前节点 → 后一个节点
```

双向链表在此基础上增加一个 `pPrev` 指针：

```c
typedef struct Node
{
    int data;
    struct Node *pPrev;
    struct Node *pNext;
} Node_t;
```

节点之间的关系：

```
NULL ← [数据] ⇄ [数据] ⇄ [数据] → NULL
```

其中：

- `pPrev`：指向前一个节点
- `pNext`：指向后一个节点

---

### 二、双向链表节点结构

例如：

```
Node_t *p1;
Node_t *p2;
Node_t *p3;
```

三个节点：

```
        pNext              pNext
p1 ─────────────→ p2 ─────────────→ p3
↑                 ↑                 ↑
│                 │                 │
└──── pPrev ──────┴──── pPrev ──────┘
```

实际上可以理解成：

```
p1                      p2                      p3
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│ pPrev = NULL│         │ pPrev = p1  │         │ pPrev = p2  │
│ data        │ ⇄       │ data        │ ⇄       │ data        │
│ pNext = p2  │         │ pNext = p3  │         │ pNext = NULL│
└─────────────┘         └─────────────┘         └─────────────┘
```

所以双向链表有两个方向：

```
正向：
head → → → → → tail

反向：
head ← ← ← ← ← tail
```

---

## 三、双向链表创建

定义节点：

```c
typedef struct Node
{
    int data;
    struct Node *pPrev;
    struct Node *pNext;
} Node_t;
```

创建一个空节点：

```c
Node_t *CreateNode(int data)
{
    Node_t *pNewNode = NULL;

    pNewNode = malloc(sizeof(Node_t));

    if(NULL == pNewNode)
    {
        printf("malloc failed\n");
        return NULL;
    }

    pNewNode->data = data;
    pNewNode->pPrev = NULL;
    pNewNode->pNext = NULL;

    return pNewNode;
}
```

注意这里和单链表最大的区别就是：

```
pNewNode->pPrev = NULL;
pNewNode->pNext = NULL;
```

一个节点有两个指针。

---

## 四、双向链表头插法

假设现在有：

```
head
 ↓
[A] ⇄ [B]
```

现在插入：

```
[X]
```

最终：

```
head
 ↓
[X] ⇄ [A] ⇄ [B]
```

代码：

```c
void InsertHead(Node_t **ppHead, Node_t *pNewNode)
{
    if(NULL == pNewNode)
    {
        return;
    }

    pNewNode->pPrev = NULL;
    pNewNode->pNext = *ppHead;

    if(NULL != *ppHead)
    {
        (*ppHead)->pPrev = pNewNode;
    }

    *ppHead = pNewNode;
}
```

这里非常重要：

```
(*ppHead)->pPrev = pNewNode;
```

因为原来的头节点也必须重新建立反向关系。

---

## 五、双向链表尾插法

原链表：

```
[A] ⇄ [B]
```

添加 `[C]`：

```
[A] ⇄ [B] ⇄ [C]
```

代码：

```c
void InsertTail(Node_t **ppHead, Node_t *pNewNode)
{
    Node_t *pCurrent = NULL;

    if(NULL == pNewNode)
    {
        return;
    }

    if(NULL == *ppHead)
    {
        *ppHead = pNewNode;
        return;
    }

    pCurrent = *ppHead;

    while(NULL != pCurrent->pNext)
    {
        pCurrent = pCurrent->pNext;
    }

    pCurrent->pNext = pNewNode;
    pNewNode->pPrev = pCurrent;
    pNewNode->pNext = NULL;
}
```

最重要的两句：

```
pCurrent->pNext = pNewNode;
pNewNode->pPrev = pCurrent;
```

必须同时修改两个方向。

---

## 六、双向链表删除节点

假设：

```
[A] ⇄ [B] ⇄ [C]
```

删除 `[B]`。

需要变成：

```
[A] ⇄ [C]
```

因此：

```
pB->pPrev->pNext = pB->pNext;
pB->pNext->pPrev = pB->pPrev;
```

完整代码：

```c
void DeleteNode(Node_t **ppHead, Node_t *pDelNode)
{
    if(NULL == ppHead || NULL == *ppHead || NULL == pDelNode)
    {
        return;
    }

    /* 删除头节点 */
    if(pDelNode == *ppHead)
    {
        *ppHead = pDelNode->pNext;

        if(NULL != *ppHead)
        {
            (*ppHead)->pPrev = NULL;
        }

        free(pDelNode);
        return;
    }

    /* 修改前一个节点 */
    if(NULL != pDelNode->pPrev)
    {
        pDelNode->pPrev->pNext = pDelNode->pNext;
    }

    /* 修改后一个节点 */
    if(NULL != pDelNode->pNext)
    {
        pDelNode->pNext->pPrev = pDelNode->pPrev;
    }

    free(pDelNode);
}
```

#### 双向链表删除的核心

记住：

```
前驱节点的 pNext
        ↓
       被删节点
        ↓
后继节点的 pPrev
```

删除时要同时处理：

```
前驱->pNext = 后继;
后继->pPrev = 前驱;
```

---

## 七、双向链表遍历

#### 正向遍历

```c
void ShowList(Node_t *pHead)
{
    Node_t *pCurrent = pHead;

    while(NULL != pCurrent)
    {
        printf("%d ", pCurrent->data);
        pCurrent = pCurrent->pNext;
    }

    printf("\n");
}
```

#### 反向遍历

如果找到尾节点：

```c
void ShowReverse(Node_t *pTail)
{
    Node_t *pCurrent = pTail;

    while(NULL != pCurrent)
    {
        printf("%d ", pCurrent->data);
        pCurrent = pCurrent->pPrev;
    }

    printf("\n");
}
```

这就是双向链表相比单链表非常明显的优势：

> **既可以从前往后，也可以从后往前。**

---

## 八、循环链表

循环链表和普通链表最大的区别：

> **最后一个节点不指向 NULL，而是重新指向第一个节点。**

普通单链表：

```
head
 ↓
[A] → [B] → [C] → NULL
```

循环单链表：

```
       ┌─────────────────┐
       ↓                 │
[A] → [B] → [C] ─────────┘
 ↑
head
```

所以：

```
C->pNext = head;
```

而不是：

```
C->pNext = NULL;
```

---

## 九、循环单链表节点

循环单链表的节点结构和普通单链表完全一样：

```c
typedef struct Node
{
    int data;
    struct Node *pNext;
} Node_t;
```

区别不在节点结构，而在于：

```
普通链表：

最后一个节点 → NULL

循环链表：

最后一个节点 → 第一个节点
```

---

## 十、循环链表遍历

这里是初学者最容易出错的地方。

普通单链表：

```
while(NULL != pCurrent)
```

循环链表不能这样写。

因为循环链表里面：

```
永远没有 NULL
```

例如：

```
A → B → C
↑       ↓
└───────┘
```

如果写：

```
while(NULL != pCurrent)
```

程序会一直循环。

所以可以这样：

```c
void ShowCircleList(Node_t *pHead)
{
    Node_t *pCurrent = pHead;

    if(NULL == pHead)
    {
        return;
    }

    do
    {
        printf("%d ", pCurrent->data);
        pCurrent = pCurrent->pNext;
    }while(pCurrent != pHead);

    printf("\n");
}
```

这里非常推荐记住：

```
do
{
    ...
}while(pCurrent != pHead);
```

---

## 十一、循环双向链表

循环链表也可以和双向链表结合起来。

普通双向链表：

```
NULL ← [A] ⇄ [B] ⇄ [C] → NULL
```

循环双向链表：

```
  ┌──────────────────────┐
  ↓                      │
[A] ⇄ [B] ⇄ [C]          │
  ↑                      │
  └──────────────────────┘
```

具体关系：

```
head->pPrev = tail;
tail->pNext = head;
```

因此：

```
head
 ↓
[A] ⇄ [B] ⇄ [C]
 ↑             ↓
 └─────────────┘
```

同时：

```
A.pPrev = C
C.pNext = A
```

---

## 十二、普通双向链表 vs 循环双向链表

| 类型 | 第一个节点 `pPrev` | 最后一个节点 `pNext` |
| --- | --- | --- |
| 普通双向链表 | `NULL` | `NULL` |
| 循环双向链表 | `tail` | `head` |

普通：

```
NULL ← A ⇄ B ⇄ C → NULL
```

循环：

```
┌───────────────┐
↓               │
A ⇄ B ⇄ C ──────┘
↑               │
└───────────────┘
```

---

## 十三、三种链表的区别

#### 1. 单链表

```
A → B → C → NULL
```

节点：

```c
struct Node
{
    int data;
    struct Node *pNext;
};
```

特点：

- 只能向后走
- 结构简单
- 节省内存
- 删除节点时需要找到前驱节点

---

#### 2. 双向链表

```
NULL ← A ⇄ B ⇄ C → NULL
```

节点：

```c
struct Node
{
    int data;
    struct Node *pPrev;
    struct Node *pNext;
};
```

特点：

- 可以正向遍历
- 可以反向遍历
- 删除节点比较方便
- 每个节点多一个指针，空间开销更大

---

#### 3. 循环链表

```
      ┌──────────────┐
      ↓              │
A → B → C ───────────┘
```

特点：

- 没有 `NULL` 作为结束标志
- 最后一个节点连接第一个节点
- 遍历时需要特别注意结束条件
- 适合需要循环访问的数据结构

例如：

```
约瑟夫环
循环队列
任务调度
```

---

## 十四、最容易出现的指针错误

#### 错误1：双向链表只修改一个方向

错误：

```
pCurrent->pNext = pNewNode;
```

却忘记：

```
pNewNode->pPrev = pCurrent;
```

结果：

```
正向：
A → B → C

反向：
C → NULL
```

链表结构已经不完整。

---

#### 错误2：循环链表使用 NULL 判断

错误：

```
while(pCurrent != NULL)
```

循环链表没有 `NULL`。

应该根据：

```
pCurrent != pHead
```

判断是否走完一圈。

---

#### 错误3：循环链表删除节点后没有重新连接

例如：

```
A → B → C → A
```

删除 B 后必须：

```
A → C → A
```

不能只：

```
free(B);
```

否则：

```
A → 已释放的B
```

后续访问就可能产生**段错误（Segmentation fault）**。

---

## 十五、重点记忆

学习链表时可以把核心规律总结成下面四句话：

#### 单链表

```
一个方向
一个指针
最后指向 NULL
```

#### 双向链表

```
两个方向
两个指针
pPrev + pNext
```

#### 循环链表

```
没有 NULL 作为结束
最后重新连接到头节点
```

#### 循环双向链表

```
既能前后移动
又首尾相连
```

最核心的指针关系一定要熟悉：

```
双向链表：

前驱 ← 当前 → 后继

当前->pPrev = 前驱
当前->pNext = 后继
```

循环双向链表则进一步变成：

```
head->pPrev = tail;
tail->pNext = head;
```
