## 一、 为什么需要单向链表？（数组 vs 链表）

| 对比维度 | 数组（Array） | 链表（Linked List） |
| --- | --- | --- |
| 物理存储 | 空间连续 | 空间不需要连续 |
| 随机访问 | 方便（通过下标索引直接访问，访问效率高） | 不太方便（需要从头结点顺序遍历） |
| 容量限制 | 必须设定上限，无法无限扩容 | 只要内存足够，元素数量无上限 |
| 插入/删除 | 需要移动大量元素，效率较低 | 只需修改指针指向，效率极高 |
| 额外开销 | 无额外指针开销 | 结点需包含指针域，增加了存储空间开销 |

### 二、 单向链表的基本物理与逻辑结构

单向链表是一种在逻辑上呈**线性一对一**结构，但在物理存储上可以**非连续**的链式表。

链表中的最小单位是**结点（Node）**，每个结点包含两部分：

1. **数据域（Data）**：存储业务数据。
2. **指针域（Next）**：存储下一个结点的地址指针。

为了方便对链表进行统一的插入和删除操作，我们通常采用带头结点（Header Node）的链表结构。头结点的数据域一般不存有效数据，其指针域指向第一个有效元素结点。

### 三、 C语言定义与核心代码实现

在C语言中，我们通常使用 `struct` 结构体来定义链表结点，并结合堆区动态分配内存（`malloc`/`free`）来管理链表空间。

#### 1. 结构体定义

```
#include <stdio.h>
#include <stdlib.h>

// 定义数据域的数据类型
typedef int ElemType;

// 定义链表结点结构体
typedef struct Node {
    ElemType data;          // 数据域
    struct Node *next;      // 指针域：指向下一个结点
} LinkNode, *LinkedList;
```

#### 2. 初始化带头结点的链表

在堆区申请一个头结点空间，并将 `next` 指针初始化为 `NULL`。

```
LinkedList list_init(void) {
    // 申请堆区空间作为头结点
    LinkedList head = (LinkedList)malloc(sizeof(LinkNode));
    if (head == NULL) {
        printf("内存分配失败！\n");
        return NULL;
    }
    head->next = NULL; // 初始化头结点的next为空
    return head;
}
```

#### 3. 头插法（Head Insert）

将新结点插入到头结点之后（即成为新的第一个有效节点）。特点：插入速度快，但数据顺序与输入顺序相反。

```c
int insert_head(LinkedList head, ElemType val) {
    if (head == NULL) return -1;

    // 创建新结点
    LinkNode *new_node = (LinkNode *)malloc(sizeof(LinkNode));
    if (new_node == NULL) return -1;

    new_node->data = val;

    // 核心指针改变：先连后断
    new_node->next = head->next;
    head->next = new_node;

    return 0;
}
```

#### 4. 尾插法（Tail Insert）

将新结点插入到链表的末尾。特点：数据插入顺序与输入顺序一致。

```c
int insert_tail(LinkedList head, ElemType val) {
    if (head == NULL) return -1;

    // 找到当前链表的最后一个结点
    LinkNode *p = head;
    while (p->next != NULL) {
        p = p->next;
    }

    // 创建新结点
    LinkNode *new_node = (LinkNode *)malloc(sizeof(LinkNode));
    if (new_node == NULL) return -1;

    new_node->data = val;
    new_node->next = NULL;

    // 将尾结点的next指向新结点
    p->next = new_node;

    return 0;
}
```

#### 5. 遍历与打印

从头结点的下一个结点开始依次向后移动指针，直到指针指向 `NULL` 为止。

```c
void list_print(LinkedList head) {
    if (head == NULL || head->next == NULL) {
        printf("LinkList: [ Empty ]\n");
        return;
    }

    LinkNode *p = head->next;
    printf("LinkList: ");
    while (p != NULL) {
        printf("%d -> ", p->data);
        p = p->next;
    }
    printf("NULL\n");
}
```

#### 6. 按值删除结点

根据给定数据匹配并删除对应节点，注意释放该节点的堆区内存。

```c
int delete_val(LinkedList head, ElemType val) {
    if (head == NULL || head->next == NULL) return -1;

    LinkNode *p = head;
    // 查找目标结点的前驱结点
    while (p->next != NULL && p->next->data != val) {
        p = p->next;
    }

    if (p->next == NULL) {
        printf("未找到值为 %d 的结点！\n", val);
        return -1;
    }

    // 保存要删除的结点
    LinkNode *del_node = p->next;
    // 跨过删除结点完成连接
    p->next = del_node->next;
    // 释放内存
    free(del_node);

    return 0;
}
```

#### 7. 销毁整个链表

逐个释放所有结点（包括头结点），防止内存泄漏。

```c
void list_destroy(LinkedList *head_ptr) {
    if (head_ptr == NULL || *head_ptr == NULL) return;

    LinkNode *p = *head_ptr;
    LinkNode *tmp = NULL;

    while (p != NULL) {
        tmp = p->next;
        free(p);
        p = tmp;
    }

    *head_ptr = NULL; // 将指针置空
}
```

### 四、 核心测试代码 (`main.c`)

```c
int main(void) {
    // 1. 初始化
    LinkedList list = list_init();

    // 2. 尾插法测试
    printf("--- 尾插法测试 ---\n");
    insert_tail(list, 10);
    insert_tail(list, 20);
    insert_tail(list, 30);
    list_print(list);

    // 3. 头插法测试
    printf("--- 头插法测试 ---\n");
    insert_head(list, 5);
    list_print(list);

    // 4. 按值删除测试
    printf("--- 删除节点 20 ---\n");
    delete_val(list, 20);
    list_print(list);

    // 5. 销毁链表
    list_destroy(&list);
    list_print(list);

    return 0;
}
```

### 五、 总结与注意事项

1. **指针修改顺序**：在做节点插入时，务必遵循 **“先连后断”** 的逻辑。例如在头插法中，必须先执行 `new_node->next = head->next`，再执行 `head->next = new_node`。若颠倒顺序，会导致后续的链表节点“断链”丢失。
2. **野指针与悬空指针**：使用 `free()` 释放堆内存后，记得将对应的指针变量置为 `NULL`，防止误引用产生野指针风险。
3. **空链表处理**：所有涉及到 `p->next` 操作的代码，都必须做好非空判断，避免访问 `NULL` 地址引发**段错误（Segmentation fault）**。

### 六、 结语

单向链表是学习复杂数据结构（如双向链表、双向循环链表、内核链表、链式栈与链式队列）的基础。理解并掌握**指针的走向**以及**堆内存的分配与释放**是手写数据结构的关键！
