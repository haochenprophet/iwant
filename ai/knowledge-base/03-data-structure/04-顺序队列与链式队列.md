## 一、队列的基本概念

队列（Queue）是一种**先进先出（FIFO，First In First Out）**的数据结构。

生活中的排队就是一个很好的例子：

```
        入队 →
┌───────────────────────┐
│ 1 │ 2 │ 3 │ 4 │ 5 │
└───────────────────────┘
  ↑                   ↑
队头                 队尾
  │                   │
出队                 入队
```

最先进入队列的数据，最先从队列中出去。

例如依次：

```
1 → 2 → 3 → 4
```

入队以后：

```
队头 → 1 2 3 4 ← 队尾
```

第一次出队：

```
1
```

第二次出队：

```
2
```

因此队列的核心特点就是：

> **先进先出。**

---

## 二、队列的基本操作

队列最基本的操作主要有：

| 操作 | 含义 |
| --- | --- |
| Create | 创建队列 |
| IsEmpty | 判断队列是否为空 |
| Enter | 入队 |
| Quit | 出队 |
| Destroy | 销毁队列 |

在代码中可以定义为：

```
CreateQueue();
IsEmptyQueue();
EnterQueue();
QuitQueue();
DestroyQueue();
```

其中：

```
EnterQueue
```

表示**入队**。

```
QuitQueue
```

表示**出队**。

---

## 三、顺序队列

顺序队列就是使用**数组**来保存队列中的数据。

例如：

```c
#define MAXSIZE 10

typedef struct
{
    DataType Data[MAXSIZE];

    int Front;
    int Rear;

} SeqQueue_t;
```

其中：

```
Front
```

表示队头。

```
Rear
```

表示队尾。

---

## 四、顺序队列的基本结构

假设：

```
MAXSIZE = 5
```

刚创建时：

```
Data：

┌───┬───┬───┬───┬───┐
│   │   │   │   │   │
└───┴───┴───┴───┴───┘
 ↑
Front
 ↑
Rear
```

假设依次加入：

```
10 20 30
```

变成：

```
┌────┬────┬────┬────┬────┐
│ 10 │ 20 │ 30 │    │    │
└────┴────┴────┴────┴────┘
  ↑              ↑
Front           Rear
```

然后出队：

```
10
```

逻辑上的队头就移动：

```
┌────┬────┬────┬────┬────┐
│ 10 │ 20 │ 30 │    │    │
└────┴────┴────┴────┴────┘
       ↑          ↑
     Front       Rear
```

这里可以发现一个问题：

> 前面的空间虽然已经出队，但数组前面的空间不能再次利用。

这就是普通顺序队列存在的**假溢出问题**。

---

## 五、循环顺序队列

为了解决顺序队列空间不能重复利用的问题，可以使用**循环队列**。

循环队列仍然使用数组，但是：

```
Rear
```

到达数组末尾后，可以重新回到数组开头。

例如：

```
┌───┬───┬───┬───┬───┐
│   │   │   │   │   │
└───┴───┴───┴───┴───┘
  ↑               ↑
  0               4
```

可以把数组看成一个环：

```
    0
 ↙     ↘
4       1
 ↖     ↗
   3 → 2
```

所以称为：

> **循环队列。**

---

## 六、循环队列的下标移动

循环队列中经常使用：

```
(index + 1) % MAXSIZE
```

让下标循环移动。

例如：

```
MAXSIZE = 5
```

当：

```
index = 4
```

执行：

```
(index + 1) % 5
```

结果：

```
(4 + 1) % 5 = 0
```

因此：

```
0 → 1 → 2 → 3 → 4 → 0 → 1 → ...
```

---

## 七、顺序循环队列代码

可以定义：

```c
typedef int DataType;

typedef struct
{
    DataType Data[10];

    int Front;
    int Rear;

} SeqQueue_t;
```

---

### 1. 创建顺序队列

```c
SeqQueue_t *CreateSeqQueue(void)
{
    SeqQueue_t *pTmpQueue = NULL;

    pTmpQueue = malloc(sizeof(SeqQueue_t));

    if(NULL == pTmpQueue)
    {
        printf("malloc failed\n");
        return NULL;
    }

    pTmpQueue->Front = 0;
    pTmpQueue->Rear = 0;

    return pTmpQueue;
}
```

---

### 2. 判断队列是否为空

```c
int IsEmptySeqQueue(SeqQueue_t *pTmpQueue)
{
    return pTmpQueue->Front == pTmpQueue->Rear ? 1 : 0;
}
```

当：

```
Front == Rear
```

表示队列为空。

---

### 3. 入队

```c
int EnterSeqQueue(SeqQueue_t *pTmpQueue, DataType TmpData)
{
    if((pTmpQueue->Rear + 1) % 10 ==
       pTmpQueue->Front)
    {
        printf("queue is full\n");
        return -1;
    }

    pTmpQueue->Data[pTmpQueue->Rear] = TmpData;

    pTmpQueue->Rear =
        (pTmpQueue->Rear + 1) % 10;

    return 0;
}
```

入队过程：

```
存数据
 ↓
Rear向后移动
```

---

### 4. 出队

```
DataType QuitSeqQueue(SeqQueue_t *pTmpQueue)
{
    DataType TmpData = 0;

    if(IsEmptySeqQueue(pTmpQueue))
    {
        return -1;
    }

    TmpData =
        pTmpQueue->Data[pTmpQueue->Front];

    pTmpQueue->Front =
        (pTmpQueue->Front + 1) % 10;

    return TmpData;
}
```

出队过程：

```
取出Front位置的数据
        ↓
Front向后移动
```

---

### 5. 销毁顺序队列

```c
int DestroySeqQueue(SeqQueue_t **ppTmpQueue)
{
    if(NULL == ppTmpQueue || NULL == *ppTmpQueue)
    {
        return -1;
    }

    free(*ppTmpQueue);

    *ppTmpQueue = NULL;

    return 0;
}
```

---

## 八、链式队列

顺序队列使用：

```
数组
```

而链式队列使用：

```
链表
```

因此链式队列不需要提前规定固定的数组大小。

基本结构：

```
队头                                      队尾
 ↓                                          ↓
┌─────┐    ┌─────┐    ┌─────┐
│ 10  │ →  │ 20  │ →  │ 30  │ → NULL
└─────┘    └─────┘    └─────┘
```

链式队列一般需要两个指针：

```
Front
Rear
```

分别指向：

```
队头
队尾
```

---

## 九、链式队列的节点

使用：

```c
typedef struct node
{
    DataType Data;

    struct node *pNext;

} Node_t;
```

这里：

```
Node_t
```

就是我们之前一直使用的结构体缩写。

---

## 十、链式队列的结构

链式队列可以设计成：

```c
typedef struct
{
    Node_t *pFront;
    Node_t *pRear;

} LinkQueue_t;
```

结构：

```
      链式队列

 pFront              pRear
   ↓                    ↓
┌────┐    ┌────┐    ┌────┐
│ 10 │ →  │ 20 │ →  │ 30 │ → NULL
└────┘    └────┘    └────┘
```

不过你之前编写的链式队列采用了**头节点**的方式：

```
┌────────┐
│ 空节点 │ → 10 → 20 → 30 → NULL
└────────┘
     ↑
  pTmpQueue
```

这种方式也非常常见。

---

## 十一、链式队列创建

按照你之前的代码风格：

```c
Node_t *CreateLinkQueue(void)
{
    Node_t *pTmpNode = NULL;

    pTmpNode = malloc(sizeof(Node_t));

    if(NULL == pTmpNode)
    {
        printf("malloc failed\n");
        return NULL;
    }

    pTmpNode->pNext = NULL;

    return pTmpNode;
}
```

这个节点是：

> **头节点，不存储实际数据。**

---

## 十二、判断链式队列是否为空

```c
int IsEmptyLinkQueue(Node_t *pTmpQueue)
{
    return pTmpQueue->pNext == NULL ? 1 : 0;
}
```

如果：

```
pTmpQueue->pNext == NULL
```

说明：

```
头节点后面没有数据节点
```

所以队列为空。

---

## 十三、链式队列入队

链式队列入队实际上就是：

> **在链表尾部插入一个节点。**

例如：

```
10 → 20 → 30
```

加入：

```
40
```

变成：

```
10 → 20 → 30 → 40
```

按照你之前使用的代码，可以这样实现：

```c
int EnterLinkQueue(Node_t *pTmpQueue,
                   DataType TmpData)
{
    Node_t *pTmpNode = NULL;
    Node_t *pLastNode = NULL;

    pTmpNode = malloc(sizeof(Node_t));

    if(NULL == pTmpNode)
    {
        printf("malloc failed\n");
        return -1;
    }

    pTmpNode->Data = TmpData;
    pTmpNode->pNext = NULL;

    pLastNode = pTmpQueue;

    while(pLastNode->pNext != NULL)
    {
        pLastNode = pLastNode->pNext;
    }

    pLastNode->pNext = pTmpNode;

    return 0;
}
```

这里的过程：

```
找到最后一个节点
       ↓
申请新节点
       ↓
保存数据
       ↓
新节点pNext = NULL
       ↓
最后一个节点指向新节点
```

---

## 十四、链式队列出队

链式队列必须从**队头删除节点**。

例如：

```
头节点 → 10 → 20 → 30
```

出队：

```
10
```

变成：

```
头节点 → 20 → 30
```

代码：

```
DataType QuitLinkQueue(Node_t *pTmpQueue)
{
    Node_t *pFreeNode = NULL;
    DataType TmpData = 0;

    if(IsEmptyLinkQueue(pTmpQueue))
    {
        return -1;
    }

    pFreeNode = pTmpQueue->pNext;

    TmpData = pFreeNode->Data;

    pTmpQueue->pNext =
        pFreeNode->pNext;

    free(pFreeNode);

    return TmpData;
}
```

这里一定要注意：

```
free(pFreeNode);
```

因为出队之后，这个节点已经不再使用，必须释放动态内存。

---

## 十五、链式队列销毁

销毁链式队列需要从头到尾逐个释放：

```c
int DestroyLinkQueue(Node_t **ppTmpQueue)
{
    Node_t *pTmpNode = NULL;
    Node_t *pFreeNode = NULL;

    if(NULL == ppTmpQueue || NULL == *ppTmpQueue)
    {
        return -1;
    }

    pTmpNode = *ppTmpQueue;

    while(pTmpNode != NULL)
    {
        pFreeNode = pTmpNode;

        pTmpNode = pTmpNode->pNext;

        free(pFreeNode);
    }

    *ppTmpQueue = NULL;

    return 0;
}
```

销毁过程：

```
头 → 10 → 20 → 30 → NULL
 ↓
free(头)
 ↓
free(10)
 ↓
free(20)
 ↓
free(30)
```

## 十六、顺序队列和链式队列的区别

| 对比 | 顺序队列 | 链式队列 |
| --- | --- | --- |
| 存储方式 | 数组 | 链表 |
| 内存 | 连续 | 不连续 |
| 容量 | 一般固定 | 动态增长 |
| 空间利用 | 循环队列较好 | 较灵活 |
| 是否需要指针 | 主要使用下标 | 大量使用指针 |
| 入队 | 修改数组下标 | 创建节点 |
| 出队 | 移动Front | 删除节点 |
| 实现难度 | 较简单 | 相对复杂 |

---

## 十七、顺序队列与链式队列的核心区别

可以简单记忆：

```
顺序队列：

数组 + Front + Rear
链式队列：

链表 + 队头 + 队尾
```

两者虽然底层实现不同，但是队列的核心规则不变：

```
入队 → 队尾
出队 → 队头
```

也就是：

```
           入队
            ↓
队头 → 10 → 20 → 30 ← 队尾
 ↑
出队
```

---

## 十八、顺序队列和链式队列在二叉树中的应用

今天学习二叉树层序遍历时使用了链式队列。

例如：

```
    1
   / \
  2   3
 / \ / \
4  5 6  7
```

层序遍历：

```
1 2 3 4 5 6 7
```

实现过程：

```
1入队
 ↓
1出队
 ↓
2、3入队
 ↓
2出队
 ↓
4、5入队
 ↓
3出队
 ↓
6、7入队
 ↓
...
```

这说明：

> **队列非常适合实现二叉树的层序遍历。**

而：

```
前序
中序
后序
```

属于深度优先遍历，更适合使用：

> **递归或者栈。**
