## 一、前言

今天主要学习了**二叉树**相关内容，包括二叉树的创建、四种遍历方式、树的高度、二叉树的销毁，以及利用**链式队列实现层序遍历**、利用**链式栈实现非递归遍历**。

通过今天的学习，可以进一步理解递归和栈、队列之间的关系。

---

## 二、二叉树的基本概念

二叉树是一种树形数据结构，每个节点最多有两个子节点，分别称为：

- 左孩子
- 右孩子

基本结构可以使用结构体表示：

```c
typedef struct btreenode
{
    int No;
    char Data;

    struct btreenode *pLeftChild;
    struct btreenode *pRightChild;

} BTreeNode_t;
```

其中：

```
Data
```

用于保存节点的数据。

```
pLeftChild
```

指向左孩子。

```
pRightChild
```

指向右孩子。

## 三、二叉树的创建

今天学习了两种二叉树创建方法。

### 1. 创建完全二叉树

对于完全二叉树，可以利用节点编号之间的关系创建。

如果当前节点编号为：

```
StartNo
```

那么：

```
左孩子 = 2 × StartNo
右孩子 = 2 × StartNo + 1
```

例如：

```
    1
   / \
  2   3
 / \ / \
4  5 6  7
```

可以递归创建：

```c
BTreeNode_t *CreateCompleteBTree(int StartNo, int EndNo)
{
    BTreeNode_t *pTmpRoot = NULL;

    pTmpRoot = malloc(sizeof(BTreeNode_t));

    if(NULL == pTmpRoot)
    {
        printf("malloc failed\n");
        return NULL;
    }

    pTmpRoot->No = StartNo;

    if(2 * StartNo <= EndNo)
    {
        pTmpRoot->pLeftChild =
            CreateCompleteBTree(2 * StartNo, EndNo);
    }
    else
    {
        pTmpRoot->pLeftChild = NULL;
    }

    if(2 * StartNo + 1 <= EndNo)
    {
        pTmpRoot->pRightChild =
            CreateCompleteBTree(2 * StartNo + 1, EndNo);
    }
    else
    {
        pTmpRoot->pRightChild = NULL;
    }

    return pTmpRoot;
}
```

## 四、通过输入创建二叉树

还可以通过终端输入字符创建二叉树。

规定：

```
# → 表示空节点
```

例如：

```
    1
   / \
  2   3
 /   / \
4   5   6
   /
  7
```

可以输入：

```
124##35#7###6##
```

创建函数：

```c
BTreeNode_t *CreateBTree(void)
{
    char ch = 0;
    BTreeNode_t *pTmpNode = NULL;

    scanf(" %c", &ch);

    if('#' == ch)
    {
        return NULL;
    }

    pTmpNode = malloc(sizeof(BTreeNode_t));

    if(NULL == pTmpNode)
    {
        printf("malloc failed\n");
        return NULL;
    }

    pTmpNode->Data = ch;

    pTmpNode->pLeftChild = CreateBTree();

    pTmpNode->pRightChild = CreateBTree();

    return pTmpNode;
}
```

这里的核心思想是：

```
读取一个字符
    ↓
如果是 #
    ↓
返回 NULL
    ↓
否则创建节点
    ↓
递归创建左子树
    ↓
递归创建右子树
```

## 五、二叉树的三种深度优先遍历

二叉树最基本的三种遍历方式：

| 遍历方式 | 顺序 |
| --- | --- |
| 前序遍历 | 根 → 左 → 右 |
| 中序遍历 | 左 → 根 → 右 |
| 后序遍历 | 左 → 右 → 根 |

例如：

```
    1
   / \
  2   3
 /   / \
4   5   6
   /
  7
```

#### 前序

```
1 2 4 3 5 7 6
```

#### 中序

```
4 2 1 7 5 3 6
```

#### 后序

```
4 2 7 5 6 3 1
```

## 六、递归实现前序遍历

前序遍历的核心：

```
根 → 左 → 右
```

代码：

```c
void PreOrderBTree(BTreeNode_t *pTmpRoot)
{
    if(NULL == pTmpRoot)
    {
        return;
    }

    printf("%c ", pTmpRoot->Data);

    PreOrderBTree(pTmpRoot->pLeftChild);

    PreOrderBTree(pTmpRoot->pRightChild);

    return;
}
```

执行过程：

```
访问根节点
    ↓
访问左子树
    ↓
访问右子树
```

## 九、二叉树的层序遍历

层序遍历又叫**广度优先遍历**，按照从上到下、从左到右的顺序访问节点。

例如：

```
    1
   / \
  2   3
 /   / \
4   5   6
   /
  7
```

层序遍历：

```
1 2 3 4 5 6 7
```

层序遍历需要使用**队列**。

因为队列的特点是：

```
先进先出 FIFO
```

所以非常适合按照节点进入的先后顺序进行处理。

基本过程：

```
根节点入队
    ↓
取出根节点
    ↓
左孩子入队
    ↓
右孩子入队
    ↓
继续取队头
    ↓
重复
```

---

## 十、链式队列实现层序遍历

今天还学习了如何让链式队列存储：

```
BTreeNode_t *
```

由于链式队列需要具有通用性，因此：

```
typedef void *DataType;
```

这样队列中的数据就可以保存任意类型的地址。

层序遍历：

```c
void LayerOrderBTree(BTreeNode_t *pTmpRoot)
{
    Node_t *plinkqueue = NULL;
    BTreeNode_t *pTmpNode = NULL;

    if(NULL == pTmpRoot)
    {
        return;
    }

    plinkqueue = CreateLinkQueue();

    EnterLinkQueue(plinkqueue, pTmpRoot);

    while(!IsEmptyLinkQueue(plinkqueue))
    {
        pTmpNode =
            (BTreeNode_t *)QuitLinkQueue(plinkqueue);

        printf("%c ", pTmpNode->Data);

        if(pTmpNode->pLeftChild != NULL)
        {
            EnterLinkQueue(plinkqueue,
                           pTmpNode->pLeftChild);
        }

        if(pTmpNode->pRightChild != NULL)
        {
            EnterLinkQueue(plinkqueue,
                           pTmpNode->pRightChild);
        }
    }

    DestroyLinkQueue(&plinkqueue);

    return;
}
```

这里第一次接触到：

```
(BTreeNode_t *)
```

这是**强制类型转换**。

因为：

```
QuitLinkQueue()
```

返回：

```
void *
```

而我们实际需要：

```
BTreeNode_t *
```

因此进行类型转换。

## 十一、求二叉树的高度

二叉树高度可以使用递归求解。

```c
int GetBTreeHigh(BTreeNode_t *pTmpRoot)
{
    int LeftHigh = 0;
    int RightHigh = 0;

    if(NULL == pTmpRoot)
    {
        return 0;
    }

    LeftHigh =
        GetBTreeHigh(pTmpRoot->pLeftChild);

    RightHigh =
        GetBTreeHigh(pTmpRoot->pRightChild);

    return (LeftHigh > RightHigh ?
            LeftHigh : RightHigh) + 1;
}
```

核心公式：

```
树的高度
=
max(左子树高度，右子树高度) + 1
```

空树：

```
高度 = 0
```

只有一个根节点：

```
高度 = 1
```

## 十二、二叉树的销毁

销毁二叉树不能直接：

```
free(根节点);
```

因为这样会导致左右子树的节点全部丢失，造成**内存泄漏**。

应该采用后序方式：

```
左子树
 ↓
右子树
 ↓
根节点
```

代码：

```c
int DestroyBTree(BTreeNode_t *pTmpRoot)
{
    if(NULL == pTmpRoot)
    {
        return 0;
    }

    DestroyBTree(pTmpRoot->pLeftChild);

    DestroyBTree(pTmpRoot->pRightChild);

    free(pTmpRoot);

    return 0;
}
```

这实际上也是一种后序遍历，只不过把：

```
printf()
```

换成了：

```
free()
```

## 十三、非递归遍历——使用栈代替递归

今天最重要的内容之一，就是：

> **递归遍历可以使用栈实现非递归遍历。**

因为递归程序运行时，系统本身就会使用**函数调用栈**保存：

- 函数调用信息
- 局部变量
- 返回地址
- 当前执行状态

因此：

```
递归
 ↓
系统栈

非递归
 ↓
自己创建栈
```

两者本质上是有联系的。

## 十四、链式栈存储二叉树节点

之前链式栈的数据类型主要是：

```
int
```

现在需要保存：

```
BTreeNode_t *
```

所以：

```
typedef void *DataType;
```

链式栈节点：

```c
typedef struct node
{
    DataType Data;
    struct node *pNext;

} Node_t;
```

这样：

```
PushLinkStack()
```

就可以把二叉树节点地址压入栈。

## 十五、非递归前序遍历

前序：

```
根 → 左 → 右
```

利用栈的：

```
后进先出
```

所以：

```
先压右
再压左
```

代码：

```c
void PreOrderBTreeNonRecursive(BTreeNode_t *pTmpRoot)
{
    Node_t *pTmpStack = NULL;
    BTreeNode_t *pTmpNode = NULL;

    if(NULL == pTmpRoot)
    {
        return;
    }

    pTmpStack = CreateLinkStack();

    PushLinkStack(pTmpStack, pTmpRoot);

    while(!IsEmptyLinkStack(pTmpStack))
    {
        pTmpNode =
            (BTreeNode_t *)PopLinkStack(pTmpStack);

        printf("%c ", pTmpNode->Data);

        if(pTmpNode->pRightChild != NULL)
        {
            PushLinkStack(pTmpStack,
                          pTmpNode->pRightChild);
        }

        if(pTmpNode->pLeftChild != NULL)
        {
            PushLinkStack(pTmpStack,
                          pTmpNode->pLeftChild);
        }
    }

    DestroyLinkStack(&pTmpStack);

    return;
}
```

记忆方法：

```
前序：

根入栈
 ↓
出栈访问
 ↓
右入栈
 ↓
左入栈
```

---

## 十六、非递归中序遍历

中序：

```
左 → 根 → 右
```

核心思想：

```
一直向左走
 ↓
节点全部入栈
 ↓
出栈
 ↓
访问
 ↓
转向右子树
```

代码：

```c
void InOrderBTreeNonRecursive(BTreeNode_t *pTmpRoot)
{
    Node_t *pTmpStack = NULL;
    BTreeNode_t *pTmpNode = NULL;

    pTmpStack = CreateLinkStack();

    pTmpNode = pTmpRoot;

    while(pTmpNode != NULL ||
          !IsEmptyLinkStack(pTmpStack))
    {
        while(pTmpNode != NULL)
        {
            PushLinkStack(pTmpStack, pTmpNode);

            pTmpNode =
                pTmpNode->pLeftChild;
        }

        pTmpNode =
            (BTreeNode_t *)PopLinkStack(pTmpStack);

        printf("%c ", pTmpNode->Data);

        pTmpNode =
            pTmpNode->pRightChild;
    }

    DestroyLinkStack(&pTmpStack);

    return;
}
```

中序遍历需要重点理解：

```
一直向左压栈
       ↓
无法继续向左
       ↓
出栈访问
       ↓
处理右子树
```

## 十七、非递归后序遍历

后序：

```
左 → 右 → 根
```

后序非递归比较复杂，可以使用**两个栈**实现。

第一个栈得到：

```
根 → 右 → 左
```

第二个栈反转以后：

```
左 → 右 → 根
```

因此得到后序遍历。

```c
void PostOrderBTreeNonRecursive(BTreeNode_t *pTmpRoot)
{
    Node_t *pTmpStack1 = NULL;
    Node_t *pTmpStack2 = NULL;

    BTreeNode_t *pTmpNode = NULL;

    if(NULL == pTmpRoot)
    {
        return;
    }

    pTmpStack1 = CreateLinkStack();
    pTmpStack2 = CreateLinkStack();

    PushLinkStack(pTmpStack1, pTmpRoot);

    while(!IsEmptyLinkStack(pTmpStack1))
    {
        pTmpNode =
            (BTreeNode_t *)PopLinkStack(pTmpStack1);

        PushLinkStack(pTmpStack2, pTmpNode);

        if(pTmpNode->pLeftChild != NULL)
        {
            PushLinkStack(pTmpStack1,
                          pTmpNode->pLeftChild);
        }

        if(pTmpNode->pRightChild != NULL)
        {
            PushLinkStack(pTmpStack1,
                          pTmpNode->pRightChild);
        }
    }

    while(!IsEmptyLinkStack(pTmpStack2))
    {
        pTmpNode =
            (BTreeNode_t *)PopLinkStack(pTmpStack2);

        printf("%c ", pTmpNode->Data);
    }

    DestroyLinkStack(&pTmpStack1);
    DestroyLinkStack(&pTmpStack2);

    return;
}
```

## 十八、今天遇到的几个典型错误

### 1. `sizeof(pTmpNode)` 写错

之前链式栈中出现：

```
malloc(sizeof(pTmpNode));
```

这里申请的是**指针大小**。

正确：

```
malloc(sizeof(Node_t));
```

应该牢记：

```
sizeof(指针)
≠
sizeof(结构体)
```

---

### 2. `No` 和 `Data` 混用

创建字符二叉树时：

```
pTmpNode->Data = ch;
```

如果遍历时却：

```c
printf("%c ", pTmpRoot->No);
```

就会出现数据错误。

因此必须保持一致：

```
CreateBTree()
    ↓
Data

遍历
    ↓
Data
```

---

### 3. `void *` 与具体指针类型

链式队列和链式栈使用：

```
typedef void *DataType;
```

取出数据时：

```
pTmpNode =
    (BTreeNode_t *)QuitLinkQueue(plinkqueue);
```

这可以让链式栈、链式队列更加通用。
